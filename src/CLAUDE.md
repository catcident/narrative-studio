# Core Library

핵심 라이브러리 (현재 미사용)

## 현재 상태

> **참고**: 모든 구현은 현재 `demo/` 디렉토리에 있습니다.
> 이 디렉토리는 향후 공유 라이브러리로 분리될 예정입니다.

`demo/src/`의 코드가 직접 사용되고 있으며, 이 `src/` 디렉토리의 코드는 활성화되지 않았습니다.

## 계획된 구조

향후 여러 프론트엔드에서 공유할 수 있는 라이브러리로 분리 시:

```
src/
├── types/          # 지식 그래프 타입 정의
│   └── index.ts    # Entity, HyperEdge, NovelKnowledgeGraph 등
├── models/         # 데이터 모델
├── services/       # 추출 서비스 (LLM 연동)
│   └── extraction.ts
├── prompts/        # AI 프롬프트 템플릿
│   └── korean.ts   # 한국어 소설 분석 프롬프트
└── index.ts        # 라이브러리 진입점
```

## 마이그레이션 계획

1. `demo/src/types.ts` → `src/types/`
2. `demo/src/services/extraction.ts` → `src/services/`
3. `demo/`에서 `src/`를 npm 패키지로 import
