## 1. 핵심 변경: 크레딧 단위 세분화

### 변경 사항

```typescript
// 변경 전
export const KRW_PER_CREDIT = 10;  // 1크레딧 = 10원 액면가

// 변경 후
export const KRW_PER_CREDIT = 2;   // 1크레딧 = 2원 액면가
```

### 변경 이유

기존 `KRW_PER_CREDIT = 10`에서는 `max(1, ceil(...))`의 올림 효과로 저가 모델의 실효 마크업이 과도했습니다:

| 모델 | 기존 마크업 | 확정 마크업 |
|------|-----------|-----------|
| Gemini Flash Lite | 10.2x | **3.1x** |
| Gemini 2.0 Flash | 7.6x | **3.1x** |
| DeepSeek V3 | 8.1x | **3.2x** |
| GPT-4o Mini | 5.1x | **3.4x** |
| GPT-4o | 3.1x | **3.1x** |
| Claude Sonnet 4 | 3.1x | **3.0x** |

**마크업 편차**: 기존 3.4배 (3.0x~10.2x) → 확정 **1.03배** (3.0x~3.4x)

서비스 전이므로 기존 사용자 마이그레이션 비용이 없어, 지금이 가장 적은 비용으로 적용 가능한 시점입니다.

### 크레딧 수식 (변경 후)

```
credits = max(1, ceil(USD_cost × 1400 × 3.0 / 2))
```

- `MARGIN = 3.0` (원가 대비 3배)
- `USD_TO_KRW = 1400` (고정 환율, 분기별 리뷰 권장)
- `KRW_PER_CREDIT = 2` (기존 10에서 변경)
- **1크레딧 최대 LLM 원가 = 2 / (3.0 × 1400) = 0.667원**

### Basic+패키지 vs Pro 교차점

```
Pro (16,900원) = Basic (4,900원) + 패키지 12,000원분
12,000원 / 1.327원(L 단가) = ~9,000 추가 크레딧
→ 총 ~14,000cr 이상 필요하면 Pro가 유리
```

**교차점: 월 ~14,000cr** — Basic 사용자가 3~4회 패키지를 반복 구매하면 Pro 전환이 합리적.

## 7. 다각도 마진 적절성 검토

### 7-1. 재무/수익성 관점

**AI SaaS 매출총이익률 벤치마크:**

| 카테고리 | 매출총이익률 |
|---------|------------|
| 일반 SaaS (상위 25%) | 75~85% |
| 일반 SaaS (중앙값) | 60~70% |
| AI SaaS (LLM 비용 포함) | 40~60% |
| AI SaaS (하위 25%) | 25~40% |

**우리 서비스 분포:**

```
               위험    주의    건전    우수
                │      │      │      │
  0%────20%────30%────40%────50%────60%────80%────100%
                │      │             │              │
           Pro최악  Pro적극      Pro일반        Basic일반
            21.9%   30.1%        46.1%          97.6%
```

**가중 평균 마진 추정** (Free 60%, Basic 30%, Pro 10% 믹스):
- Free: 매출 0원 (원가 미미)
- Basic 평균: ~60% (사용률 40~60%, 저가 모델 위주)
- Pro 평균: ~45% (사용률 60~80%, 혼합 모델)
- **전체 유료 가중 평균: ~55%** → AI SaaS 기준 중앙~상위

**판정: 양호**. 가중 평균 55%는 AI SaaS 벤치마크의 건전한 수준.

### 7-2. 사용자 공정성 관점

**마크업 균일성:**

| 비교 | 기존 | 확정 |
|------|------|------|
| 마크업 범위 | 3.0x ~ 10.2x | 3.0x ~ 3.4x |
| 편차 | 3.4배 | **1.03배** |

모든 모델에서 **3x 내외의 균일한 마크업** → 사용자가 어떤 모델을 선택하든 공정한 가격.

**크레딧 가치 직관성:**

```
1크레딧 ≈ 소설 1,700자 분석 (Gemini Flash 기준)
2크레딧 ≈ 소설 1페이지
```

**판정: 우수**. 모델 간 가격 차별 해소, 직관적 가치 매핑 가능.

### 7-3. 경쟁 포지셔닝 관점

**장편소설 1편 분석 비용 비교:**

| 접근 방식 | 비용 |
|----------|------|
| StoryGraph Free + Gemini Flash | **0원** |
| StoryGraph Basic + Gemini Flash | **~58원** (59cr × 0.98원) |
| StoryGraph Pro + Claude Sonnet | **~1,182원** (1,399cr × 0.845원) |
| ChatGPT Plus 직접 사용 | 28,000원/월 (구조화 분석은 수동 작업) |
| OpenRouter 원가 (Gemini Flash) | ~1.3원 (자체 구축 필요) |
| OpenRouter 원가 (Claude Sonnet) | ~45원 (자체 구축 필요) |

- ChatGPT/Claude 대비: **압도적으로 저렴** (월정액 대비 건당 과금)
- OpenRouter 원가 대비: 3x 마크업 → 자동 분석 + 시각화 + 관리 기능의 부가가치로 정당화
- 3x가 부담스러운 파워 유저 → **BYOK(Pro 전용)**로 원가 사용 가능

**가격 인하 여력:** 유사 서비스가 2x 마크업으로 경쟁해도, Basic 마진 33%(최악)~98% 범위에서 대응 가능.

**판정: 우수**. 경쟁 대비 가격 경쟁력 충분, 가격 전쟁에서도 여력 있음.

### 7-4. 성장/전환 관점

**퍼널 단계별 마진 역할:**

| 단계 | 마진 | 역할 | 적절성 |
|------|------|------|--------|
| Free | -100% (손실) | 가치 체험 + 전환 유도 | 적절. 보너스 1,000cr로 장편 ~25편(Flash) 분석 가능 |

| Basic | 33~98% | 주 수익원 (가장 많은 유료 사용자) | 우수. 최악에서도 33% |
| Basic → Pro | - | 교차점 ~14,000cr. 패키지 반복 구매 경험 → Pro 전환 학습 | 적절 |

**BYOK 자동 교정 메커니즘:**

```

  → "매달 크레딧이 부족"
  → BYOK로 자기 API 키 사용 (크레딧 소비 0)
  → 서비스 마진 100% (16,900원 전액 플랫폼 이용료)
```

**판정: 양호**. Pro 최악 시나리오가 BYOK로 자연 수렴하는 구조.
