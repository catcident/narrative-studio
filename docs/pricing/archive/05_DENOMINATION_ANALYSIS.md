## 1. 핵심 질문

> "1크레딧 = 1원으로 완전 투명하게 가면, 오히려 지출을 억제하는 효과가 있지 않을까?"

**결론부터: 그렇습니다.** 행동경제학 연구와 업계 사례가 일관되게 보여주는 바, 가격이 실제 화폐와 1:1로 매핑되면 **"지불의 고통(Pain of Paying)"이 극대화**되어 사용자의 지출 의향이 현저히 낮아집니다.

## 2. 핵심 이론적 근거

### 2-1. 지불의 고통 (Pain of Paying)

**Prelec & Loewenstein (1998, Marketing Science)** — "The Red and the Black"

지불은 소비와 별개의 **부정적 감정 반응(고통)**을 유발합니다. 이 고통의 크기는 **결합도(coupling)**에 따라 결정됩니다:

- **강한 결합** (현금): 소비 시점에 지불을 즉시 떠올림 → 고통 최대
- **약한 결합** (신용카드, 토큰): 지불과 소비가 분리됨 → 고통 감소 → 지출 증가

**핵심 원리: 지불과 소비 사이의 추상화 계층이 많을수록, 지불의 고통이 줄어들고 지출이 증가합니다.**

### 2-2. 신경과학적 증거 (fMRI 연구)

**MIT Sloan (2021, Scientific Reports):**
- 신용카드 결제 시 뇌의 **선조체(striatum)** 활성화 — 도파민 보상 회로, 중독성 물질과 동일 영역
- 현금 결제 시에는 보상 회로가 활성화되지 않음
- **신용카드는 단순히 "브레이크를 푸는" 것이 아니라 "가속 페달을 밟는" 것** — 기존 이론보다 강한 메커니즘

**Frontiers in Psychology (2019) — 현금 vs 카드 vs 스마트폰 fMRI:**
- 현금 노출 시 **두정엽 + 우측 뇌섬엽(insula)** 활성화 — 물리적 고통/혐오를 처리하는 동일 영역
- 카드/스마트폰에서는 이 영역이 거의 활성화되지 않음
- **가상 크레딧은 현금에서 가장 멀리 떨어진 추상화** → 뇌섬엽 활성화 최소화

### 2-3. 실제 지출 차이 데이터

| 연구/출처 | 발견 |
|----------|------|
| Dun & Bradstreet | 신용카드 사용 시 현금 대비 **12~18% 더 지출** |
| MIT Sloan (fMRI) | 신용카드가 보상 회로를 직접 활성화 |
| Federal Reserve Bank of Boston | 현금 평균 거래: $22 vs 비현금: $112 (**5.1배 차이**) |
| Raghubir & Srivastava (2008, APA) | 스크립(상품권)이 동일 액면의 현금보다 **더 많이 지출**됨 |
| ValuePenguin 종합 | 신용카드로 **최대 83%** 더 지출 |

### 2-4. 카지노 칩 효과

카지노가 현금 대신 칩을 사용하는 이유:
- 참가자들이 칩으로 **현금보다 유의미하게 더 많이 도박**함 (Psychology Today)
- $350을 현금으로 베팅하려면 물리적으로 지폐를 세야 하므로 주저하게 됨 → 칩 하나로는 이 주저가 사라짐
- 칩의 색상과 디자인이 위험 감수를 더 유발 — 돈이 아닌 "게임 도구"로 인식

**크레딧 시스템은 디지털 카지노 칩과 동일한 메커니즘**: 실제 화폐 → 추상 단위로 전환하여 지불의 고통을 감소시킴.

### 2-5. 전망 이론 (Prospect Theory, Kahneman & Tversky 1979)

- **손실이 이득보다 ~2배 강하게 느껴짐** (손실 회피)
- 크레딧 잔액 감소 = 손실 → 추상적 크레딧이면 손실의 "실제 금액"이 모호해져 고통 감소
- **준거점 의존성**: 준거점이 "나에게 1,000크레딧이 있다"이면, 50크레딧 지출은 작은 손실. 준거점이 "이것은 500원이다"이면, 동일 거래가 실제 화폐 손실 회피를 촉발

### 2-6. 심적 회계 (Mental Accounting, Thaler 1985/1999)

- 사람들은 돈을 **별도의 심적 계좌**로 분류하며, 계좌마다 다른 지출 규칙을 적용
- **크레딧은 별도의 심적 계좌를 생성**: "AI 분석 크레딧" 계좌는 "생활비" 계좌와 다른 규칙
- 커피 한 잔(5,000원)에는 고민하면서도, 분석 50크레딧에는 망설이지 않을 수 있음 — 다른 계좌이므로
- **구독 크레딧 = "공돈" 효과**: 월 정기 지급되는 크레딧은 "이미 지불한 돈"으로 인식 → "카지노 하우스 머니" 효과로 더 자유롭게 지출

### 2-7. 베버-페히너 법칙 (Weber-Fechner Law)

- **자극의 변화 감지는 원래 자극의 비율에 의존**
- 잔액 10,000크레딧에서 50크레딧 사용 = 0.5% 감소 → 거의 인식 안 됨
- 잔액 100크레딧에서 50크레딧 사용 = 50% 감소 → 매우 크게 느껴짐
- **큰 숫자의 잔액이 개별 거래를 "감지 불가" 수준으로 만듦**

### 2-8. 수량 효과 (Numerosity Effect, Huang et al. 2020, Information Systems Research)

이 연구가 **가장 직접적으로 관련됩니다:**

- 환율이 **비현저(non-salient)**할 때: 높은 수량성(5,000코인 vs 5젬)이 항목을 **더 비싸게** 느끼게 함
- 환율이 **현저(salient)**할 때: 높은 수량성이 항목을 **더 저렴하게** 느끼게 하여 구매 의향 증가

**1크레딧 = 1원이면 환율이 최대로 현저(salient)**합니다. 이 경우:
- 큰 숫자(118크레딧 = 118원)가 "비싸다"가 아니라 "정확히 118원"으로 즉시 환산됨
- 추상화의 이점이 완전히 상실됨
- **크레딧이 화폐의 별명(alias)에 불과해짐** → 심적 회계 분리 효과 없음

## 3. 업계 사례 분석

### 3-1. 의도적 비(非) 1:1 비율 설계

| 서비스 | 크레딧 단위 | 실제 환율 | 전략 |
|--------|-----------|----------|------|
| Fortnite V-Bucks | 1 V-Buck | ~1센트 ($7.99/1,000) | 비정수 환율로 암산 방해 |
| Roblox Robux | 1 Robux | ~1.25센트 ($9.99/800) | 비정수 환율 + 대량 보너스 |
| 네이버 쿠키 | 1쿠키 | ~100원 (2,000원/20쿠키) | 깔끔한 1:100 비율, 한국 표준 |
| 카카오 초코 | 1초코 | ~10원 (2,000원/200초코) | 1:10 비율 |
| 포인트(네이버페이) | 1포인트 | 1원 | 1:1이지만 "리워드"로 프레이밍 |

**핵심 관찰:**
- **게임 화폐**: 비정수 환율로 최대 추상화 (V-Bucks, Robux)
- **한국 콘텐츠 플랫폼**: 깔끔한 비율(1:10~1:100)으로 적정 추상화 (쿠키, 초코)
- **결제 포인트**: 1:1이지만 "리워드/적립"으로 프레이밍하여 심적 회계 분리 (네이버페이)

### 3-2. 왜 1:1로 가지 않는가

**모바일 게임 업계의 일관된 선택:**
- 50%의 한국 모바일 게임 지출이 인게임 화폐 구매 (Mistplay 2024)
- **모든** 주요 게임이 비1:1 환율 사용
- 이유 (Game Voyages):
  1. **가격 난독화**: "2,000젬에 500" → 달러로 암산이 어려움
  2. **행동 프레이밍**: 가상화폐 지출 = "게임 행위" vs 현금 지출 = "쇼핑 행위"
  3. **지불 분리**: 실제 결제는 젬 구매 시 이미 완료 → 이후 젬 지출은 "무료"처럼 느껴짐
  4. **잔여 화폐 함정**: 번들과 아이템 가격의 의도적 불일치 → 잔여 화폐가 추가 구매 유도

### 3-3. 투명성이 역효과를 낸 사례

**Uber 서지 프라이싱 (2013~2016):**
- 기존: "2.5X 배수" 표시 → 완전 투명
- 결과: 극심한 소비자 반발, 경쟁사(Lyft) 시장 점유율 확대
- 대응 (2016): **배수 제거**, "사전 가격 표시"로 전환 → 서지가 보이지 않게 내장
- **교훈: 가격 매커니즘의 투명성(배수 표시)이 금액 자체보다 더 큰 부정적 인식 유발**

**Everlane (패션):**
- 원가 분해 공개 (소재, 인건비, 운송비, 마진)
- 초기: 대히트 — 웨이팅리스트 7만 명, 매출 $100M+, YoY 200% 성장
- 장기: **마진 제한** — 소비자가 생산 원가에 앵커링되어 "합리적" 수준 이상 마크업 거부
- **교훈: 원가 투명성은 마케팅으로는 효과적이나, 장기 가격 결정력을 제약**

**Vercel v0 (2025):**
- 무제한 AI → 크레딧 기반 전환
- 결과: "대량 이탈", 커뮤니티에서 구독 취소 선언 쇄도
- 사용자: "몇 번의 프롬프트만에 크레딧이 소진됐다"
- **교훈: 투명한 사용량 과금이 평탄 요금보다 "더 비싸게" 느껴짐** (실제 비용이 동일하더라도)

### 3-4. 상품화 함정 (Commodity Trap)

Lincoln Murphy (SixteenVentures):
> "고객이 당신의 SaaS 가격을 원재료 비용과 직접 비교하기 시작하면 상품화 함정에 빠진 것이다."

1GB 스토리지에 $20/월을 청구하는데, 고객이 AWS S3가 GB당 $0.023인 것을 알면 → 마크업이 노출 → 신뢰 하락.

**StoryGraph에 적용:**
- 1크레딧 = 1원이면, 사용자가 OpenRouter API 가격을 조회하고 마크업을 직접 계산 가능
- "Gemini Flash 청크가 원가 1원인데 왜 3원(3크레딧)을 받지?" → 상품화 함정
- 추상적 크레딧이면 이 비교가 불가능하거나 매우 어려움

### 3-5. 투명성이 긍정적으로 작용하는 경우

모든 투명성이 나쁜 것은 아닙니다:

**HBS 연구 (Mohan, Buell & John):**
- 원가 투명성이 구매 확률을 **21~22% 증가**시킨 사례
- **단, 이것은 "원가 투명성"(생산 비용 공개)이지 "가격 투명성"(마크업 공개)이 아님**
- 자발적 원가 공개 → 신뢰 형성 → 구매 의향 증가
- **마진이 높다는 것이 드러나면 오히려 역효과**

**B2B 고객의 68%**가 명확한 가격 체계에 추가 비용을 지불할 용의 있음 (McKinsey)

**결론: "무엇을 제공하는가"의 투명성(가치 투명성)은 좋고, "원가가 얼마인가"의 투명성(비용 투명성)은 위험합니다.**

## 4. KRW_PER_CREDIT 옵션 비교

### 4-1. 세 가지 옵션의 다차원 비교

| 평가 기준 | KRW=1 (완전 투명) | KRW=2 (저추상) | KRW=10 (적정 추상) |
|----------|-----------------|---------------|------------------|
| **환율 현저성** | 최대 (즉시 환산) | 높음 (쉽게 환산) | 낮음 (암산 필요) |
| **지불의 고통** | 최대 | 높음 | **낮음** |
| **심적 회계 분리** | 없음 (=원화) | 약함 | **강함** |
| **상품화 함정 위험** | 최대 | 높음 | **낮음** |
| **마크업 균일성** | 3.0~3.1x (최고) | 3.0~4.1x | 3.0~10.2x (최저) |
| **베버-페히너 효과** | 약함 (작은 잔액) | 중간 | **강함** (큰 잔액) |
| **한국 시장 친숙도** | 네이버페이 포인트 | 해당 없음 | **카카오 초코 유사** |
| **마크업 비가시성** | 가시적 | 가시적 | **비가시적** |
| **보너스 크레딧 효과** | 약함 (= 원화 할인) | 중간 | **강함** (추상 단위 증가) |

### 4-2. 사용자 관점 시뮬레이션

**시나리오: Basic 사용자가 장편소설 분석을 시작하려 할 때**

**KRW_PER_CREDIT = 1 (완전 투명):**
```
잔액: 6,000크레딧

"해리 포터" 분석 예상 비용:
  Gemini Flash: 118크레딧 (= 118원)
  Claude Sonnet: 2,740크레딧 (= 2,740원)

사용자 심리:
  "Sonnet이 2,740원이나 하네... Flash는 118원이고..."
  "내 Basic이 4,900원인데, Sonnet 2번이면 5,480원... 본전도 못 뽑겠네"
  → 원가 비교 + 본전 계산 시작 → 지출 억제
```

**KRW_PER_CREDIT = 10 (적정 추상):**
```
잔액: 1,000크레딧

"해리 포터" 분석 예상 비용:
  Gemini Flash: 39크레딧
  Claude Sonnet: 299크레딧

사용자 심리:
  "Flash 39크레딧이면 25번 이상 할 수 있네, 넉넉하다"
  "Sonnet은 299... 좀 비싸지만 3번은 할 수 있으니"
  → 크레딧 단위로 사고, 원화 환산하지 않음 → 지출 자연스러움
```

**차이점:**
- KRW=1: "2,740원"이라는 숫자가 실생활 소비(커피, 교통비)와 직접 비교됨
- KRW=10: "299크레딧"은 실생활 비용과 비교 대상이 없음 → 크레딧 체계 내에서만 판단

### 4-3. 마크업 비균일성은 실제로 문제인가?

PRICING_FINAL.md가 `KRW_PER_CREDIT = 2`로 변경한 핵심 근거는 "마크업 균일성"이었습니다:
> "모든 모델에서 3x 내외의 균일한 마크업 → 어떤 모델을 선택하든 공정한 가격"

**그러나 리서치 결과, 이 근거는 약합니다:**

1. **사용자는 마크업을 모릅니다**: 사용자가 보는 것은 "Flash 39크레딧 vs Sonnet 299크레딧"이지, "Flash 마크업 10x vs Sonnet 마크업 3x"가 아닙니다
2. **마크업을 알 수 있는 사용자 = BYOK 사용자**: OpenRouter 가격을 조회하고 마크업을 계산할 수 있는 기술적 사용자는 정확히 BYOK를 사용할 사용자 → 크레딧을 소비하지 않음
3. **비균일 마크업이 비즈니스에 유리**: 저가 모델의 높은 마크업(10x)은 사실상 **최소 수수료** 역할. 서비스 운영비(서버, 개발, 인프라)를 보상. 고가 모델의 낮은 마크업(3x)은 프리미엄 모델 사용을 합리적 가격에 제공
4. **업계 표준이 비균일**: 모든 게임 화폐, SaaS 크레딧이 비균일 마크업을 사용. 사용자는 이를 불공정하다고 인식하지 않음 (인식 자체가 불가능)

**유일한 실질적 위험**: 경쟁사가 "우리는 균일한 3x 마크업"이라고 마케팅하는 경우 — 하지만 현재 한국 시장에 직접 경쟁자가 없음.

## 5. 권장안: `KRW_PER_CREDIT = 10`

### 5-1. 권장 근거 요약

| 근거 | 설명 |
|------|------|
| **지불의 고통 최소화** | 1:10 비율은 즉각적 원화 환산을 방해 (Prelec & Loewenstein) |
| **심적 회계 분리** | "크레딧"이 별도 심적 계좌로 작동 (Thaler) |
| **한국 시장 적합** | 카카오 초코(1:~10), 네이버 쿠키(1:100)와 유사한 비율 |
| **베버-페히너 효과** | 잔액 1,000cr에서 39cr 지출 = 3.9% → 감지 어려움 |
| **상품화 함정 회피** | OpenRouter 원가와의 직접 비교 차단 |
| **보너스 크레딧 효과 극대화** | "보너스 200크레딧" > "보너스 200원" (심리적 가치) |
| **구현 비용 = 0** | 현재 코드의 KRW_PER_CREDIT = 10 그대로 유지 |

### 5-2. 마크업 비균일성 대응 전략

`KRW_PER_CREDIT = 10`의 유일한 단점인 마크업 비균일성(3x~10x)은 다음으로 완화:

**즉시 적용:**
1. **총액 표시**: 사용자에게 청크별 비용이 아닌 **분석 전체 예상 크레딧**만 표시
2. **가치 투명성**: "이 분석에 39크레딧이 소비됩니다" (비용 투명성 X, 가치 투명성 O)
3. **모델 간 비교 프레이밍**: "Flash: 39cr (경제적) vs Sonnet: 299cr (정밀)"

**중기 (3~6개월):**
4. **세션 일괄 차감**: 청크별이 아닌 분석 단위로 크레딧 산정 → 올림 효과 감소
   - Flash 장편: 청크별 39cr → 세션 기준 ceil(원가합계 × 환율 × 마진 / 10) ≈ 8cr
   - 마크업이 ~3x로 자연 수렴 (올림이 1회만 발생)

- KRW=2: Flash 청크 = 2cr (마크업 3.05x), 장편 59cr

## 6. 추가 심리학적 전략

### 6-1. 크레딧에 브랜드 이름 부여

연구에 따르면 "크레딧"보다 고유 이름이 **보유 효과(endowment effect)**를 더 강하게 유발합니다:
- 초콜릿 코인으로 실험 시 → 보유 효과 발생
- "토큰"으로 프레이밍된 초콜릿 코인 → 보유 효과 사라짐

**제안**: "크레딧" 대신 **"잉크(Ink)"** 또는 **"페이지(Page)"** 같은 서비스 맥락의 이름

```
"잔여 잉크: 847"  vs  "잔여 크레딧: 847"  vs  "잔액: 847원"
```

"잉크"는:
- 소설/글쓰기 맥락에 자연스러움
- "원"과 완전히 다른 심적 범주
- 보유 효과 + 손실 회피 극대화 ("내 잉크가 줄어든다")
- 비교 가능한 외부 기준이 없음 (커피 3,000원과 비교 불가)

### 6-2. 보너스 크레딧으로 환율 앵커 차단

보너스 크레딧은 1:1 환산을 **영구적으로 파괴**하는 가장 효과적인 도구:

```
Basic 구독: 4,900원 → 1,000크레딧 + 보너스 50크레딧
  → "1크레딧 = 4.67원? 4.90원? 어느 쪽이지?"
  → 정확한 환율 계산이 불가능해짐
```

### 6-3. "페니-어-데이" 리프레이밍 (Gourville 1998)

가격 표시에 일간 환산 적용:

```
❌ "Pro 플랜: 월 16,900원"
✅ "Pro 플랜: 하루 563원으로 무제한 분석"
```

연구 결과: 일간 환산 시 수락률이 **30% → 52%**로 증가 (73% 향상).
