## 1. Executive Summary

### 기존 확정안(PRICING_FINAL.md)의 핵심 문제

| 문제 | 심각도 | 근거 |
|------|--------|------|
| Free(500cr)가 너무 관대 — 월 8편 분석 가능 | **치명적** | 일반 독자 월 2~4편 → 전환 동기 없음 |
| Basic→Pro 전환 유인 부족 (BYOK/파일크기뿐) | 높음 | 12,000원 가격 점프에 비해 인지 가치 부족 |
| 기업/출판사 대상 티어 부재 | 높음 | B2B 시장 진입 불가, 팀 기능 없음 |
| API 접근 정책 부재 | 중간 | 프로그래밍 방식 분석 수요 미대응 |
| 기능 차별화 없이 크레딧 양으로만 차등 | 높음 | 업계 best practice는 기능+사용량 하이브리드 |

### 제안 방향

1. **Free/Basic 축소**: 크레딧 하향 + 기능 게이팅 (채팅 횟수, 저장 수, 내보내기)
2. **Business 신설**: 5석 팀 플랜, API 접근, 시리즈 분석, 출판사/스튜디오 타겟
3. **Enterprise 신설**: Contact Sales, SSO/감사로그, 맞춤 SLA
4. **Pro 가치 강화**: PDF 보고서, 일괄 분석, 우선 큐, 이월 허용
5. **API 접근은 Business 이상만**: 외부 연동은 프리미엄 기능으로 위치

## 2. 업계 리서치 핵심 발견

### 2-1. AI SaaS 요금제 트렌드 (2025-2026)

**하이브리드 과금이 표준**: 구독 + 크레딧/사용량 모델이 41%로 급증 (전년 27%→41%), 순수 좌석 기반은 21%→15%로 감소. 크레딧 기반 도입은 YoY 126% 성장.

**3+1 티어 구조가 최적**: Free / Pro / Business + Enterprise(Contact Sales). 4개 이상의 공개 티어는 선택 피로(choice paralysis)를 유발. Enterprise는 가격 앵커 역할 + 고가치 고객 포획.

**기능 게이팅 > 순수 사용량 게이팅**: 업계 연구에 따르면 기능의 80%를 무료로 제공하되 핵심 20%를 유료에 배치하는 하이브리드가 가장 높은 전환율 달성. 사용량만으로 차등하면 한계가 있음.

|------|-------------------|--------|
| Spotify | 광고 + 셔플 전용 + 오프라인 불가 | ~6% |
| Zoom | 40분 회의 제한 | ~4% |
| Dropbox | 2GB 스토리지 | ~4% |
| Grammarly | 100 AI 프롬프트/월 + 프리미엄 제안 회색 표시 | ~8% |

| **StoryGraph 제안** | **150cr (장편 2.5편) + 기능 제한** | **목표 5~7%** |

### 2-5. 출판/콘텐츠 기업의 니즈

리서치에서 확인된 출판사/콘텐츠 기업의 핵심 요구:

1. **대량 원고 심사**: 편집자가 슬러시 파일을 AI로 선별, 월 수십~수백 편
2. **팀 협업**: 여러 편집자가 같은 분석 결과 공유, 코멘트, 역할 기반 접근
3. **시리즈 분석**: 다권짜리 시리즈의 인물/관계 변화 추적
4. **일괄 처리**: 여러 원고를 큐에 등록, 우선순위 관리
5. **보안/컴플라이언스**: 미출간 원고 기밀 유지, 감사 로그, 데이터 레지던시
6. **시스템 연동**: 기존 편집 시스템에 API로 통합

## 4. 각 티어 설계 근거

### 4-1. Free (150cr/월, 500cr 가입보너스)

**설계 원칙: "맛보기는 충분하되, 부족함을 느끼게"**

| 항목 | PRICING_FINAL 확정안 | 본 제안 | 변화 |
|------|---------------------|---------|------|
| 월 크레딧 | 500 | **150** | -70% |
| 가입보너스 | 1,000 | **500** | -50% |
| 첫 달 합계 | 1,500 | **650** | -57% |

**150cr/월의 분석 가능량:**

| 모델 | 장편(100K자) | 단편(20K자) | 대하소설(500K자) |
|------|-------------|------------|----------------|
| Gemini Flash | **~2.5편** | ~21편 | **~0.8편** (부족) |
| DeepSeek V3 | ~2.5편 | ~21편 | ~0.8편 |

**전환 심리 설계:**
- **1개월차** (650cr): Flash 장편 ~11편 → 서비스 가치를 **충분히** 체험. "이 서비스 좋다!"
- **2개월차** (150cr): Flash 장편 ~2.5편 → **적극적 독자(월 4편+)에게 부족함 시작**
- **3개월차**: 채팅 3회 제한 + 그래프 3개 제한과 결합 → "Basic이면 무제한인데..."

**업계 벤치마크 대비:**
- Zoom: 40분 제한 — "회의가 끊기는" 불편함으로 전환 유도
- Grammarly: 100 AI 프롬프트 — "더 좋은 제안이 보이지만 사용 불가" 불편함
- **StoryGraph**: 150cr — "소설 3편 분석했는데 4번째가 안 돼" → 자연스러운 업그레이드 포인트

**기능 게이팅의 역할:**

| 제한 | 전환 트리거 | 심리적 효과 |
|------|-----------|-----------|
| 채팅 3회/분석 | 분석 결과에 질문하고 싶은데 횟수 소진 | "핵심 가치를 맛봤지만 더 원함" — 업계에서 가장 강력한 전환 유도 |
| 저장 3개 | 4번째 소설 분석 시 "공간 부족" | 축적된 데이터의 손실 회피(loss aversion) 심리 활용 |
| 히스토리 3개 | 수정 이력 추적 불가 | 파워 유저에게만 중요 — 정확한 타겟팅 |
| 내보내기 불가 | 관계도를 블로그/SNS에 공유하고 싶지만 불가 | 바이럴 욕구 → 업그레이드 또는 입소문 유도 |

### 4-2. Basic (4,900원/월, 3,000cr)

**설계 원칙: "개인 사용자의 주력 티어, 합리적 가격에 충분한 가치"**

| 항목 | PRICING_FINAL 확정안 | 본 제안 | 변화 |
|------|---------------------|---------|------|
| 월 크레딧 | 5,000 | **3,000** | -40% |
| cr당 수입 | 0.98원 | **1.633원** | +67% |

**3,000cr/월 분석 가능량:**

| 모델 | 장편 | 단편 | 대하소설 |
|------|------|------|---------|
| Gemini Flash | **~50편** | ~430편 | ~15편 |
| GPT-4o Mini | ~38편 | ~330편 | ~12편 |
| GPT-4o | **~2.9편** | ~25편 | ~0.9편 |
| Claude Sonnet | **~2.1편** | ~18편 | ~0.7편 |

**왜 3,000cr인가:**
- 저가 모델(Flash): 월 50편 → **일반 독자에게 과잉 (이건 의도적)** → 저가 모델 사용 유도 = 높은 마진
- 고가 모델(Sonnet): 월 ~2편 → **부족함 발생** → Pro 전환 유인 또는 패키지 구매
- 4,900원에 50편 분석 가능 = **소설 1편당 ~98원** → 압도적 가성비 인식

**Basic과 Free의 "기능 절벽" (feature cliff):**

| 기능 | Free | Basic | 체감 차이 |
|------|------|-------|----------|
| 모델 | 2종 | **전체 (9종)** | 높음 |
| 채팅 | 3회/분석 | **무제한** | **매우 높음** |
| 저장 | 3개 | **20개** | 높음 |
| 내보내기 | 불가 | **PNG** | 중간 |

채팅 무제한이 가장 강력한 전환 유인. 분석 결과에 대해 AI에게 계속 질문하는 것은 서비스의 핵심 가치이며, 3회 제한에서 무제한으로의 점프는 **가격 대비 가장 큰 인지 가치 향상**.

**웹소설 작가 시나리오:**

**Basic→Pro 교차점 분석:**

```
Pro (16,900원) = Basic (4,900원) + 12,000원 추가 비용
12,000원 / 1.327원(패키지L 단가) = ~9,043 추가 크레딧
→ 총 ~12,043cr 이상 필요하면 Pro가 유리
```

교차점이 ~12,000cr이므로, Basic 3,000cr의 4배를 쓰는 사용자부터 Pro 전환이 합리적. 이 지점은:
- Sonnet으로 장편 ~8.6편/월 = 프리미엄 모델 헤비 유저
- Flash로 장편 ~203편/월 = 비현실적
- **현실적 교차**: 혼합 모델(Flash 60% + GPT-4o 40%)로 장편 ~28편/월

### 8-5. BYOK 포지셔닝

**BYOK를 "절약" 이 아닌 "자유"로 포지셔닝:**

```
❌ "BYOK로 크레딧 비용을 절약하세요"  → 구독 가치 훼손
✅ "나만의 API 키로 무제한 분석"      → 프리미엄 자유도 강조
```

BYOK는 Pro/Business에서 사용 가능하되, 마케팅에서는 "크레딧 걱정 없이 무제한"이라는 프리미엄 가치로 포지셔닝. 이는 구독료(16,900원/79,000원)를 **플랫폼 이용료**로 정당화.

## 11. 리스크 및 대응

### 11-1. Free 축소로 인한 사용자 이탈

**리스크**: 기존 무료 사용자가 "너무 인색하다"고 느끼고 경쟁 서비스(NovelWorld 등)로 이탈.

**대응:**
- 가입보너스 500cr로 첫 경험은 풍성하게 유지
- 150cr/월이라도 Flash 장편 2.5편 = 일반 독자 충분
- 채팅 3회 제한이지만 분석 자체는 무제한 (크레딧 내)
- 경쟁사(NovelWorld)는 무료이지만 기능 미숙 → 품질 차별화

### 11-2. Business 티어 수요 불확실

**리스크**: Business 티어를 구축했지만 사용자가 없는 경우.

**대응:**
- Phase 2(3~6개월)에 구현 → 사전 수요 확인 후 투자
- Enterprise "문의" 페이지를 먼저 두고 실제 문의를 수집
- 문의 없으면 Business 구현을 연기하고 개인 티어 최적화에 집중

### 11-3. Pro 마진 역전 (기존 문제 유지)

**리스크**: Pro 최악 시나리오에서 21.9% 마진 (환율 1,500원 시 16%).

**대응:**
- BYOK 자동 교정 메커니즘 (파워 유저 → BYOK → 원가 0)
- 환율 분기별 리뷰 (`USD_TO_KRW` 수동 조정)
- Pro 사용자의 실제 모델 믹스 모니터링 → Sonnet 100% 비율이 30% 초과 시 가격 조정 검토

### 11-4. API 남용

**리스크**: Business 사용자가 API를 과도하게 사용하여 서버 부하 증가.

**대응:**
- Rate limit (60/분) + 월간 호출 제한 (10,000/월)
- 크레딧 차감이 자연적 제한 역할 (크레딧 소진 → API도 차단)
- 이상 사용 패턴 모니터링 + 알림

### 11-5. 한국 시장 가격 저항

**리스크**: 79,000원/월 Business 가격이 한국 시장에서 높게 인식될 수 있음.

**대응:**
- 한국 B2B SaaS 참고: 클로바노트 20,000원/월(회사당), 타입캐스트 39,000원/월
- 79,000원은 5석 포함 → 석당 15,800원 → 클로바노트보다 약간 낮은 수준
- 연간 결제 시 월 65,833원 → 석당 ~13,167원
- ROI 명확화: "편집자 1명의 시급 < 월 15,800원의 AI 분석" → 자명한 가치

## 13. 결론

### 핵심 메시지

1. **Free/Basic 축소 + 기능 게이팅**이 전환율 향상의 핵심. 크레딧 양만으로는 차등화가 약하며, 채팅 횟수·저장 수·내보내기 같은 기능 차등이 가장 강력한 전환 유인.

2. **Business 티어**는 웹소설 플랫폼/출판사의 실제 니즈(팀 협업, API 연동, 대량 분석)에 대응하며, API 접근을 프리미엄 기능으로 위치시키는 것은 Copy.ai/Canva/Grammarly 등 업계 표준과 일치.

3. **Enterprise는 "문의" 페이지만 두고 시작**하되, 가격 앵커 역할 + 대형 고객 포획 파이프라인으로 기능. 실제 구현은 수요 확인 후.

4. **현재가 최적 시점**: 서비스 런칭 전이므로 기존 사용자 마이그레이션 비용 없이 구조를 재설계할 수 있음. "가격 인상은 쉽지만 인하는 어렵다"는 SaaS 원칙에 따라, 보수적으로 시작하고 데이터 기반으로 조정.

5. **마진은 건전**: 가중 평균 ~61.5%로 AI SaaS 상위 수준. 모든 유료 티어에서 최악의 경우에도 20%+ 마진 유지.
