### 3-3. 패키지 → 구독 전환 유인: **강함**

```
패키지 S: 4,900원 / 550cr (8.91원/cr)

→ 동일 금액에서 Basic이 1.45배 효율적
```

### 3-4. Basic+패키지 vs Pro 교차점

```
Pro (16,900원) = Basic (4,900원) + 12,000원 추가

12,000원으로 패키지 구매:
  Pkg M(1,200cr, 9,900원) → 나머지 2,100원 (추가 구매 불가)

→ 크레딧: 2,000cr vs 3,000cr → Pro가 50% 더 많음
→ 기능까지: Pro 압도적 우위
→ 가격: 14,800원 vs 16,900원 (차이 2,100원에 1,000cr + 기능)
```

## 5. 극단적 케이스 분석

### 5-1. Denial of Wallet (대용량 파일)

**시나리오**: Pro 사용자, 50MB 텍스트(~5백만 자, 1,000 청크), Sonnet

```
extraction: 1,000 × $0.03252 = $32.52
selector:     999 × $0.0005  = $0.4995
total: $33.02

session_credits = ceil(33.02 × 5.0 × 150) = ceil(24,765) = 24,765cr

Pro 잔액: 3,000cr
→ "예상 크레딧(24,765cr)이 잔액(3,000cr)을 초과합니다" 경고 표시

Flash로 동일 파일:
  total: $0.93 + $0.50 = $1.43
  credits = ceil(1.43 × 9.63 × 150) = ceil(2,066) = 2,066cr
  → Pro 3,000cr이면 가능
```

**판정: ✓ 세션 예약으로 DoW 사전 차단**

### 5-3. 채팅 컨텍스트 윈도우 크리프


### 6-3. 볼륨 디스카운트의 마진 영향
