## 1. 제외된 항목 (구현 계획 없음)

### 시리즈 연결 분석

- **원안**: Business 전용. 여러 지식그래프를 연결하여 시리즈 전체 분석
- **제외 사유**: 현재 사용자 규모에서 수요 불확실. 단일 파일/일괄 분석으로 충분
- **영향**: 기능 매트릭스에서 삭제, Business 티어 차별화 요소에서 제거

### 누적 보상

- **원안**: Pro 이상, 분기 내 패키지 3회 구매 시 다음 패키지 +20% 보너스
- **제외 사유**: 복잡한 로직 대비 효과 불확실. 반복 구매 유도는 자동 리로드로 대체 가능
- **PRICING.md 참조**: Section 11-4, 항목 5

### 리퍼럴 프로그램

- **원안**: 유료 사용자 1,000명+ 시 도입. 추천인/피추천인 크레딧 보상
- **제외 사유**: 유료 사용자 규모 미달. 남용 방지 로직 복잡
- **PRICING.md 참조**: Section 14, Phase 3

### 시즌 프로모션 체계

- **원안**: 분기별 이벤트 — 패키지 구매 시 +30% 보너스, 구독 전환 연계 프로모션
- **제외 사유**: 운영 오버헤드 대비 효과 불확실. 첫 구매 보너스(+50%)로 초기 전환 유도 충분
- **PRICING.md 참조**: Section 11-4, 항목 6

## 2. 보류된 항목 (수요 기반 구현)

### 팀 워크스페이스 + RBAC

- **원안**: Business 전용. 팀 풀링 크레딧, 좌석 관리(+15,900원/석), 역할 기반 접근제어(관리자/편집자/뷰어)
- **트리거**: Business 플랜 가입 5건 이상
- **난이도**: 높음 (백엔드 팀 모델 + 초대 시스템 + 권한 미들웨어 + UI)
- **현재 상태**: Business = Pro + 크레딧 증량(16,000cr)으로 운영 중

### 공개 API v1

- **원안**: Business 이상. REST API로 외부 시스템에서 분석 기능 호출
- **엔드포인트 초안**:
  ```
  POST /api/v1/analyze           텍스트 → 지식그래프
  GET  /api/v1/knowledge-graphs  저장된 분석 목록
  GET  /api/v1/knowledge-graphs/:id  개별 분석 조회
  POST /api/v1/chat              분석 결과 AI 질의
  GET  /api/v1/usage             잔여 크레딧, API 사용량
  ```
- **Rate Limit 초안**: Business 10,000 calls/월, 60/분, 동시 3건
- **과금**: 웹 UI와 동일한 세션 크레딧 수식 적용
- **트리거**: API 문의 3건 이상
- **난이도**: 높음 (API 키 발급 + 인증 미들웨어 + 사용량 추적 + 문서화)

### Enterprise 기능

- **원안**: SSO/SAML 인증, 감사 로그, 전담 CSM, 커스텀 SLA(99.9%+), 데이터 레지던시, 커스텀 Rate Limit
- **트리거**: Enterprise 문의 3건 이상
- **난이도**: 높음 (SSO 연동 + 감사 로깅 인프라 + SLA 모니터링)
- **현재 상태**: UI에서 Enterprise 카드 완전 제거됨 (2026-02-07). rateLimit.ts에서도 enterprise 항목 삭제. 문의 시 별도 대응

## 3. UI만 구현, 백엔드 결제 연동 대기

> 아래 항목은 프론트엔드 UI가 완성되어 있으나, 실제 결제 처리를 위한 백엔드 연동이 필요.

### 연간 결제 (17% 할인)

- **현재**: SubscriptionPage에 월간/연간 토글, 할인가 표시
- **필요**: 백엔드 결제 게이트웨이 연동 (Stripe/토스페이먼츠 등)
- **금액**: Basic 49,000원/yr, Pro 169,000원/yr, Business 790,000원/yr

### 자동 리로드 + 10% 보너스

- **현재**: 임계값 선택 (50/100/200cr) + 패키지 선택 (S/M/L) UI
- **필요**: 백엔드 자동 결제 트리거 + 보너스 크레딧 지급 로직
- **보너스**: S 550→605, M 1,200→1,320, L 2,800→3,080

### 첫 패키지 구매 보너스 +50%

- **현재**: 패키지 탭에 "+50% 보너스" 배너 + 보너스 적용 크레딧 표시
- **필요**: 백엔드 `first_package_purchased` 플래그 + 보너스 크레딧 지급
- **보너스**: S 550→825, M 1,200→1,800, L 2,800→4,200

### 구독 플랜 결제

- **현재**: 플랜 카드에 가격 표시, "구독하기" 버튼은 비활성 또는 외부 링크
- **필요**: 결제 게이트웨이 연동 + 구독 생명주기 관리 (생성/갱신/취소/다운그레이드)
