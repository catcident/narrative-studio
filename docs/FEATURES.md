# 기능 상세 설명

## 1. 관계도 뷰 (RelationshipGraph)

### 노드 표시
- **인물 (character)**: 파란색 원형 노드
- **장소 (location)**: 초록색 사각형 노드
- **조직 (organization)**: 보라색 노드
- **아이템 (item)**: 주황색 작은 노드
- **기타**: 회색 작은 점 노드

### 엣지 (관계선)
- **색상**: 관계 유형별 색상 구분
  - 가족: 보라색
  - 연인: 분홍색
  - 친구: 초록색
  - 적대: 빨간색
  - 소유/소속: 주황색
  - 위치: 청록색
- **스타일**: 감정에 따른 선 스타일
  - 긍정: 실선
  - 부정: 점선
  - 중립: 짧은 점선
- **라벨**: 관계 유형 한글 표시

### 뷰 모드

#### 전체 모드
- 모든 엔티티와 관계 표시
- 중요도 필터 슬라이더 (1~10)
- 낮은 중요도 엔티티 숨기기 가능

#### 간소화 모드
- 인물 노드만 표시
- 인물 간 관계만 표시
- 복잡한 그래프 단순화에 유용

#### 인물 중심 모드
- 특정 인물 선택 (다중 선택 가능)
- 선택된 인물이 중앙에 배치
- 선택된 인물과 직접 연결된 관계만 표시
- 관련 없는 엔티티는 숨김

### 인터랙션
- **노드 클릭**: 상세 정보 패널 열기
- **노드 드래그**: 위치 이동 (위치 유지됨)
- **엣지 클릭**: 관계 상세 팝업
- **배경 클릭**: 선택 해제
- **줌/팬**: 마우스 휠, 드래그

---

## 2. 상세 정보 패널 (DetailPanel)

### 엔티티 정보
- 이름, 별칭
- 카테고리 (인물/장소/조직 등)
- 설명

### 속성 정보
- 성별, 나이, 직업
- 소속, 현재 위치
- 성격, 외모, 능력
- 기타 커스텀 속성

### 등장 장면
- **첫 등장**: 노란색 강조 박스
  - 장면 번호
  - 시간/장소
  - 요약
- **전체 등장 장면 목록**: 스크롤 가능

### 관계 목록
- 감정별 그룹화 (긍정/부정/기타)
- 각 관계 카드:
  - 관계 유형 및 서브타입
  - 관계 강도 (10단계 바)
  - 쌍방향 여부
  - 관계 설명
  - 시점별 관점 (있는 경우)
  - 등장 장면 목록 (스크롤 가능)

## 3. 연대기 뷰 (CharacterChronicle)

### 레이아웃
- **가로축**: 캐릭터별 컬럼
- **세로축**: 장면 순서
- **셀**: 해당 장면에서의 캐릭터 이벤트

### 장면 라벨 (왼쪽 고정)
- 장면 번호
- 장소 / 시간
- 시간 경과 표시 (이전 장면과 다를 경우)

### 이벤트 카드
- 헤더: 장면 번호, 장소/시간
- 관계 목록:
  - 관계 유형 태그
  - 상대방 이름
  - 관계 설명
- 색상: 감정에 따른 배경색
  - 긍정: 연두색
  - 부정: 연분홍색
  - 중립: 회색

### 인터랙션
- **드래그 스크롤**: 마우스로 상하좌우 이동
- **캐릭터 클릭**: 해당 캐릭터 컬럼 강조
- **초기화**: 선택 해제

### 캐릭터 필터
- 상단 캐릭터 아이콘 클릭
- 선택된 캐릭터만 강조 표시
- 다른 캐릭터는 투명하게

---

## 4. 파일 업로드 및 분석

### 지원 형식
- **.txt**: 일반 텍스트 파일
- **.pdf**: PDF 문서 (pdf.js로 텍스트 추출)

### 분석 프로세스
1. 파일 읽기 및 텍스트 추출
2. 청크 분할 (긴 텍스트의 경우)
3. AI API 호출 (Gemini)
4. 응답 파싱 및 병합
5. 온톨로지 구축
6. 자동 저장

### 청크 처리
- 최대 청크 크기: 약 30,000자
- 이전 청크의 엔티티 정보 전달 (컨텍스트 유지)
- 진행률 표시

### 에러 처리
- API 오류 시 재시도
- 부분 실패 시 성공한 부분만 사용
- 진행 상황 로컬 저장 (중단 후 재개 가능)

---

## 5. 데이터 관리

### 자동 저장
- 분석 완료 시 자동 저장
- 로컬 스토리지 사용
- 제목 기반 ID 생성

### 버전 히스토리
- 저장할 때마다 버전 증가
- 이전 버전 목록 조회
- 특정 버전으로 복원 가능

### 파일 추가 (병합)
- 기존 분석 결과에 새 파일 추가
- 엔티티 중복 제거 (이름/별칭 매칭)
- 관계 병합

### 내보내기/가져오기
- JSON 형식으로 내보내기
- JSON 파일 가져오기
- 다른 기기에서 데이터 이동 가능

### 저장 데이터 그리드
- 4열 카드 레이아웃
- 제목, 엔티티 수, 관계 수, 장면 수
- 마지막 수정 시간
- 버전 번호
- 호버 시 액션 버튼 (히스토리/내보내기/삭제)

---

## 6. 장면 타임라인 (SceneTimeline)

### 하단 슬라이더
- 전체 장면 범위 표시
- 드래그로 장면 범위 선택
- 선택된 범위의 관계만 그래프에 표시

### 장면 범위 필터
- 시작/끝 장면 선택
- 범위 내 관계만 활성화
- 범위 외 관계는 투명하게 표시

---

## 7. 세계관 뷰 (WorldView)

### 장소 기반 시각화
- 장소 엔티티 중심 배치
- 해당 장소와 관련된 인물/아이템 표시
- 장소 간 이동 관계 시각화

---

## 8. 기타 기능

### 반응형 UI
- 다양한 화면 크기 지원
- 패널 크기 조절

### 키보드 단축키
- ESC: 선택 해제
- 방향키: 장면 이동

### 성능 최적화
- React useMemo/useCallback 활용
- 가상화 (대량 노드 시)
- 디바운싱 (검색, 필터)
