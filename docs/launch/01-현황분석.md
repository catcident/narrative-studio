# 01. 현황 분석

> catcident.com과 storygraph의 현재 상태 및 기술 스택

## catcident.com (메인 웹사이트)

### 기술 스택

| 기술 | 용도 |
|------|------|
| Django 5.2+ | 백엔드 프레임워크 |
| django-hosts | 서브도메인 라우팅 (www, cms, default) |
| Vite 5 | 프론트엔드 빌드 |
| Tailwind CSS 4 | 스타일링 |
| Alpine.js | 인터랙티브 요소 |
| HTMX | 서버 드리븐 HTML |
| PostgreSQL | 데이터베이스 |
| Redis | 캐시 / Celery 브로커 |
| Celery | 비동기 태스크 (구독 갱신, hold 만료 등) |

### 현재 네비게이션 구조

**메인 네비게이션**:
- 소개 (드롭다운: 역사, 창작자, 캐릭터 등)
- 뉴스
- 이벤트
- 갤러리
- 자료실
- 스토어 → 네이버 스마트스토어 외부 링크 (`smartstore.naver.com/sadam_media`)
- 라이선스

**우측 아이콘**: 로그인, 언어 선택 (한/영), 다크모드 토글

**푸터**:
- 회사 소개 (역사, 창작자, 캐릭터)
- 서비스 (도서, 리소스, 라이선스)
- 정보 및 이벤트 (뉴스, 이벤트)
- 법적 정보 (이용약관, 개인정보 처리방침)
- **FAMILY SITES**: 야옹이왕 블로그, 전기장판 출판사, 사담미디어

### CMS 모델 (네비게이션 관련)

```
NavigationGroup     — 메인 네비 항목 (href, open_in_new_tab, highlighted)
NavigationSubMenu   — 드롭다운 서브 메뉴
FooterSection       — 푸터 섹션
FooterSubMenu       — 푸터 하위 링크
FamilySite          — 패밀리 사이트 링크
SiteTitle           — 사이트 제목 (싱글톤)
HeroSlide           — 홈페이지 슬라이더
HomeSection         — 홈페이지 섹션
```

모든 모델은 `django-parler`로 다국어 지원 (한국어/영어, 한국어 폴백).

### 서브도메인 라우팅

| 서브도메인 | 용도 |
|-----------|------|

### 인증 시스템

**두 가지 사용자 유형**:

| 유형 | 인증 방식 | 관리 위치 |
|------|----------|----------|
| Staff (관리자) | 이메일 + OTP (TOTP/이메일) | cms.catcident.com |
| Member (일반) | 이메일 인증 → 비밀번호 | www.catcident.com |

**OAuth/OIDC Provider**:
- `django-oauth-toolkit` 기반
- 스코프: `openid`, `profile`, `email`, `member`, `billing`
- PKCE 필수 (public clients)
- 토큰 TTL: access 1시간, refresh 30일, auth code 5분

### 과금 시스템 (Billing)

**상태: 크레딧 기반 과금 완전 구현, 결제 게이트웨이 미구현**

**모델 구조**:

| 모델 | 코드 | 용도 |
|------|------|------|
| Service | B01 | 서비스 등록 (storygraph) |
| ServicePlan | B02 | 구독 플랜 |
| CreditPackage | B03 | 크레딧 상품 |
| ServiceSubscription | B04 | 사용자 구독 |
| CreditLedger | B05 | 거래 원장 (append-only) |
| CreditHold | B06 | 크레딧 선점 (hold) |

**플랜**:

| 플랜 | 월 크레딧 | 가격 | 특이사항 |
|------|----------|------|---------|
| Free | 50 | 0원 | 가입 보너스 100cr |
| Basic | 800 | 4,900원 | |
| Pro | 3,000 | 16,900원 | |
| Business | 16,000 | 79,000원 | |
| Internal | 무제한 | - | 스태프 전용, BYOK 활성 |

**크레딧 패키지**:

| 패키지 | 크레딧 | 가격 | 보너스 |
|--------|--------|------|--------|
| 스타터 | 550 | 4,900원 | 0% |
| 스탠다드 | 1,200 | 9,900원 | 10% |

**서비스 인증**: `X-Service-Key` 헤더 (SHA256 해시) + `service=storygraph` 파라미터

**Celery 태스크**:
- `daily_credit_reset_check` — 월간 크레딧 리셋
- `check_subscription_expiry` — 만료 구독 상태 전환
- `expire_stale_holds` — 5분 간격 hold 정리

- **과금**: hold/settle/release 세션 패턴, 프록시로 catcident-backend 연결

### 과금 연동

```
클라이언트 (React)
  → Next.js API Routes (/api/billing/*, /api/session/*)
    → billingProxy.ts (서버 사이드 검증 + sanitization)
      → catcident-backend /billing/* 엔드포인트
```

**세션 패턴**:
1. `checkSufficientBalance()` → 잔액 > 0 확인
2. `holdCredits(estimatedAmount)` → 예상 크레딧 선점
3. `extractKnowledgeGraph()` → 청크별 분석 (토큰 사용량 수집)
4. 성공: `settleCredits()` → 실제 사용량 정산 / 실패: `releaseCredits()` → hold 해제

### Docker 배포

- Multi-stage 빌드 (deps → builder → runner)
- Alpine 기반, non-root 사용자 (nextjs:1001)
- Healthcheck: `GET /api/config` (공개 API, 인증 리다이렉트 회피)
- 네트워크: internal + caddy (리버스 프록시)
