# 02. 브랜딩 전략

> 스토리그래프의 브랜드 아키텍처, 네이밍, 비주얼 아이덴티티

## 브랜드 아키텍처 모델 선택

### 후보 모델 비교

| 모델 | 패턴 | 사례 | 적합도 |
|------|------|------|--------|
| **Branded House** | "모 브랜드 + 서비스명" | Google Docs, Apple Music | 모 브랜드 인지도가 높을 때 |
| **Endorsed Brand** | "서비스명 by 모 브랜드" | Jira by Atlassian, Crack by 뤼튼 | 독립 성장 + 모 브랜드 신뢰 |
| **Sub-brand** | "모 브랜드 + 서비스명" (차별화 스타일링) | Notion AI, Notion Calendar | 긴밀한 통합 + 고유 정체성 |
| **Independent** | 완전 독립 브랜드 | WhatsApp (by Meta) | 별도 타겟 오디언스 |

### 결정: Endorsed Brand

**"스토리그래프 by 고양이의 만행"** (영문: "StoryGraph by Catcident")

**선택 이유**:
- 고양이의 만행은 아직 성장 중인 브랜드 → StoryGraph가 독자 정체성을 가져야 서비스 자체의 브랜드 파워 구축 가능
- StoryGraph는 도서 출판과는 다른 AI 도구 영역 → 모 브랜드와 타겟이 겹치지만 서비스 성격이 다름
- "by 고양이의 만행" 보증으로 기존 회원의 신뢰 전이
- 향후 고양이의 만행을 모르는 사용자도 유입 가능

## 비주얼 아이덴티티

### 색상 체계

| 요소 | catcident.com (모 브랜드) | storygraph (서비스) | 관계 |
|------|--------------------------|---------------------|------|
| 배경 | 다크 (#18181b) | 다크 (#18181b) | **공유** |
| 주 액센트 | 퍼플 (#7C3AED 계열) | 블루-인디고 (#3b82f6 → #6366f1) | **차별화** |
| 보조 액센트 | - | 바이올렛 (#8b5cf6) | 고유 |
| 그라디언트 | - | blue-500 → indigo-600 | 고유 |

**근거**: storygraph는 현재 블루-인디고 계열을 사용 중. 모 브랜드 퍼플과 보색 관계를 유지하면서 독자성 확보.

### 아이콘/로고

| 요소 | catcident.com | storygraph |
|------|---------------|------------|
| 메인 아이콘 | 다이아몬드 형태 (고양이 관련) | Network 아이콘 (그래프/노드) |
| 아이콘 스타일 | 단색 + 배경 | 흰색 + 그라디언트 배경 |
| 파비콘 | 고양이의 만행 로고 | Network 아이콘 (현재 구현됨) |

**"by 고양이의 만행" 배지**:
- 위치: 헤더 로고 옆 또는 아래
- 스타일: 작은 텍스트 + 모 브랜드 아이콘 (10-12px)
- 클릭 시: catcident.com으로 이동

### 타이포그래피

- **공유**: 시스템 폰트 스택 (Tailwind 기본)
- 양쪽 사이트 동일한 폰트 체계 유지
- 커스텀 폰트 도입 시 양쪽 동시 적용 권장

### 다크/라이트 모드

- catcident.com: 쿠키 기반 테마 토글 지원
- storygraph: 현재 다크 전용
- **권장**: 양쪽 모두 다크/라이트 토글 지원, 기본값 다크
