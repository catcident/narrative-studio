## 런칭 전 필수 확인 항목

### 기술

- [ ] storygraph.catcident.com 프로덕션 접속 확인
- [ ] OAuth 로그인 흐름 정상 작동
- [ ] 과금 hold/settle/release 정상 작동
- [ ] 크레딧 잔액 갱신 정상
- [ ] 파일 업로드 + AI 분석 정상
- [ ] 모든 뷰 탭 (관계도, 타임라인, 연대기, 세계관, 원본, 채팅) 정상
- [ ] 내보내기 (PNG/SVG/PDF) 정상
- [ ] 반응형 디자인 (모바일, 태블릿)

### 법률/정책

- [ ] 이용약관 (스토리그래프 서비스 조항 포함)
- [ ] 개인정보처리방침 (AI 분석, 소설 원본 저장 관련)
- [ ] 결제/환불 정책 (TossPayments 연동 후)
- [ ] 저작권 안내 (업로드 소설의 저작권 책임)

### 비즈니스

- [ ] 가입 보너스 크레딧 확인 (100cr)
- [ ] 무료 플랜 월 크레딧 확인 (50cr)
- [ ] 유료 플랜 가격 최종 확인
- [ ] 크레딧 패키지 가격 최종 확인
- [ ] TossPayments 테스트 키 → 프로덕션 키 전환
- [ ] 결제 영수증 발행 확인

### 모니터링

- [ ] 에러 추적 (Sentry 또는 대안)
- [ ] 업타임 모니터링 (healthcheck 엔드포인트)
- [ ] API 응답 시간 로깅
- [ ] 과금 이상 감지 (unusually large settle 등)

### 콘텐츠

- [ ] 랜딩 페이지 카피 검토
- [ ] 스크린샷 에셋 준비
- [ ] 데모 영상 (선택)
- [ ] FAQ 또는 도움말

## 리스크 및 대응

| 리스크 | 영향 | 대응 |
|--------|------|------|
| TossPayments 승인 지연 | 결제 기능 런칭 지연 | Phase 1 (랜딩+브랜딩)을 먼저 런칭, 결제는 후속 |

| 크레딧 소진 후 이탈 | 전환율 저하 | 잔액 알림 (이미 구현), 충전 유도 UI |
| 법률 이슈 (소설 저작권) | 서비스 중단 위험 | 이용약관에 면책 조항 + 사용자 책임 명시 |
