# 03. 네비게이션 연동

> catcident.com ↔ storygraph 양방향 네비게이션 설계

## 현재 구조

### catcident.com 네비게이션

```
메인 네비:  소개(▼) | 뉴스 | 이벤트 | 갤러리 | 자료실 | 스토어(→외부) | 라이선스
우측 아이콘: 로그인 | 언어(🌐) | 다크모드(🌙)
```

### catcident.com 푸터

```
회사 소개          서비스              정보 및 이벤트      법적 정보
├─ 역사           ├─ 도서             ├─ 뉴스             ├─ 이용약관
├─ 창작자         ├─ 리소스           └─ 이벤트           └─ 개인정보
└─ 캐릭터         └─ 라이선스

FAMILY SITES: 야옹이왕 블로그 | 전기장판 출판사 | 사담미디어
```

### storygraph 네비게이션 (현재)

```
좌: 로고 + "인물 관계도" | 뷰 탭 6개
우: CreditBadge | UserMenu
```

푸터 없음.

---

## 연동 설계

### 방안 A: catcident.com에서 storygraph 노출

#### A-1. 메인 네비게이션 "서비스" 항목 추가

```
메인 네비:  소개(▼) | 서비스(▼) | 뉴스 | 이벤트 | 갤러리 | 자료실 | 스토어 | 라이선스
                      │
                      ├─ 스토리그래프 — AI 인물 관계도
                      └─ (향후 추가 서비스)
```

**구현**: CMS `NavigationGroup` 모델로 "서비스" 그룹 생성 → `NavigationSubMenu`로 스토리그래프 추가

```python
# CMS 데이터 (setup 커맨드 또는 어드민에서)
NavigationGroup(
    order=2,  # "소개" 다음
    href=None,  # 드롭다운 전용 (클릭 시 이동 없음)
)
# Translation: title="서비스"

NavigationSubMenu(
    group=services_group,
    href="https://storygraph.catcident.com",
    open_in_new_tab=False,  # 같은 도메인 체계이므로 새 탭 불필요
    order=1,
)
# Translation: title="스토리그래프", description="AI 인물 관계도"
```

#### A-2. 푸터 연동

**옵션 1**: 기존 "서비스" 섹션에 추가
```
서비스
├─ 도서
├─ 리소스
├─ 라이선스
└─ 스토리그래프 (NEW)   ← FooterSubMenu 추가
```

**옵션 2**: FAMILY SITES에 추가
```
FAMILY SITES: 야옹이왕 블로그 | 전기장판 출판사 | 사담미디어 | 스토리그래프
```

**권장**: 두 곳 모두 추가. "서비스" 섹션은 자체 서비스, FAMILY SITES는 외부 사이트 느낌이므로 "서비스" 섹션이 더 적절.

#### A-3. 홈페이지 프로모션 (선택)

홈페이지에 스토리그래프 소개 카드 또는 배너 추가. `HomeSection` 모델 활용 가능.

### 방안 B: storygraph에서 catcident.com 연결

#### B-1. 헤더 "by 고양이의 만행" 배지

```
┌─────────────────────────────────────────────────┐
│ [Network] 스토리그래프  by 고양이의 만행  |  탭들...  │
│           ─────────── ──────────────────         │
│           메인 로고     작은 배지 (클릭 → catcident.com)   │
└─────────────────────────────────────────────────┘
```

**구현 방식**:
- 배지: 텍스트 "by 고양이의 만행" (12px, text-gray-400)
- 또는: 모 브랜드 아이콘 + 텍스트
- 클릭: `https://catcident.com` 으로 이동
- 모바일: "by" 배지 숨김 가능 (반응형)

#### B-2. 공유 푸터

storygraph에 푸터 추가 (현재 없음):

```
┌──────────────────────────────────────────────┐
│ 스토리그래프                                   │
│ AI 인물 관계도 by 고양이의 만행                  │
│                                               │
│ 서비스        고양이의 만행      법적 정보       │
│ ├─ 기능 소개   ├─ catcident.com  ├─ 이용약관    │
│ ├─ 가격       ├─ 뉴스          └─ 개인정보     │
│ └─ 문의       └─ 이벤트                        │
│                                               │
│ © 2026 고양이의 만행. All rights reserved.      │
└──────────────────────────────────────────────┘
```

#### B-3. 프로덕트 스위처 (향후)

서비스가 2개 이상이 되면 Google 와플 메뉴 또는 Atlassian 프로덕트 스위처 패턴 도입:

```
[⊞] 클릭 →  ┌──────────────┐
             │ 스토리그래프   │
             │ (현재 서비스)  │
             ├──────────────┤
             │ 서비스 B      │
             │ 서비스 C      │
             ├──────────────┤
             │ catcident.com │
             └──────────────┘
```

현재는 서비스가 1개이므로 "by 고양이의 만행" 배지로 충분.

## 인증 흐름 연동

이미 구현됨:

```
storygraph.catcident.com → "Catcident 계정으로 로그인" 버튼
  → catcident.com/oauth/authorize/ (OIDC + PKCE)
    → 사용자 로그인/가입
    → storygraph.catcident.com/api/auth/callback/catcident (리다이렉트)
```

**변경 불필요**: OAuth 흐름은 그대로 유지. 단, 로그인 페이지의 텍스트와 디자인만 브랜딩에 맞게 업데이트.
