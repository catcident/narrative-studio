## 4. 플랜별 사용 시나리오

### Free 플랜 (100 크레딧/월)
- Gemini Flash로 단편 **~14편** 또는 장편 **0.8편** (부족)
- Claude Sonnet로 단편 **~1.7편** (거의 1편만 가능)
- 채팅 10회 ≈ 30~50 크레딧 추가 소비

**평가**: 장편소설 1편도 분석 못 끝내는 수준. 서비스 가치를 충분히 체험하기 어려움.

### Basic 플랜 (1,000 크레딧/월, 4,900원)
- Gemini Flash: 장편 **~8편** + 채팅 여유
- GPT-4o: 장편 **~1.5편**
- Claude Sonnet: 장편 **~1편** (거의 전 크레딧 소진)

**평가**: 저가 모델 중심이면 넉넉, 프리미엄 모델은 빠듯.

### Pro 플랜 (5,000 크레딧/월, 14,900원)
- Gemini Flash: 장편 **~42편** (과잉)
- GPT-4o: 장편 **~7편** + 채팅 여유
- Claude Sonnet: 장편 **~5편**

**평가**: 대부분의 개인 사용자에게 충분. BYOK 옵션으로 Heavy user 대응.

## 5. 심각한 문제 분석 (Critical Issues)

### 5-1. Pro 플랜 마진 역전 위험

| 항목 | Pro 구독 | 실제 원가 (최악) |
|------|---------|----------------|
| 크레딧당 수입 | 2.98원 | - |
| 크레딧당 원가 (Claude Sonnet) | - | 3.25원 |
| 5,000크레딧 수입 | 14,900원 | - |
| 5,000크레딧 원가 | - | **16,250원** |
| **손실** | | **-1,350원/월** |

**시나리오**: Pro 사용자가 Claude Sonnet만 사용하고 5,000 크레딧을 전부 소진하면 **월 1,350원 적자**.

**현실적 위험도**: 중간. 대부분 사용자는 기본 모델(Gemini Flash) 사용, 모든 크레딧 소진도 드뭄. 하지만 파워 유저 1명이 발생하면 일반 유저 9명의 이익이 필요.

**업계 참조**: SaaS 업계 표준 마크업은 원가 대비 30~50%인데, 이 서비스의 MARGIN=3.0(200% 마크업)은 높은 편. 그런데도 구독 플랜 할인이 너무 깊어 **Pro에서 역전 발생**.

**권장 조치**:
- Pro 월 크레딧을 4,000으로 하향하거나, 가격을 17,900원으로 인상
- 또는 프리미엄 모델 사용 시 크레딧 가중치 적용 (예: Claude Sonnet = 1.5x)

### 5-2. USD_TO_KRW 하드코딩 (환율 리스크)

```typescript
export const USD_TO_KRW = 1400;
```

2026년 2월 현재 실제 환율은 약 1,440~1,470원대. 하드코딩된 1,400원은 이미 3~5% 과소. 환율이 1,500원으로 올라가면 **모든 크레딧의 실제 마진이 7% 축소**.

**최악 시나리오**: 환율 1,600원 → 마진 14% 축소 → Pro 플랜에서 더 큰 적자.

**권장 조치**: 분기별 환율 리뷰 + 수동 업데이트, 또는 환율 API 연동.

### 5-3. 크레딧 패키지 미출시

현재 "준비 중" 상태. Basic/Pro 사용자가 크레딧을 다 쓰면 **다음 달까지 대기**하는 수밖에 없음. 이는 과금 기회 손실이자 사용자 이탈 유인.

업계 데이터: 크레딧 추가 구매는 SaaS 수익의 15~30%를 차지하는 핵심 수익원 (Metronome 2025 Field Report).

### 5-4. 월간 크레딧 만료, 이월 없음

매월 미사용 크레딧이 소멸되고 새로 지급됨. 이는:
- **장점**: 사용 촉진, 예측 가능한 원가
- **단점**: 고객 불만의 최대 원인 중 하나 (Stigg 엔지니어링 팀 보고)

**업계 관행**: 12개월 만료가 타협안. 프리미엄 티어에 제한적 이월(예: 최대 20% 이월) 허용하는 것이 일반적.

## 6. 극단적 케이스 분석

### 6-1. 대용량 파일 공격 (Denial of Wallet)

Pro 사용자가 50MB 텍스트 파일(약 5천만 자, 10,000 청크)을 Claude Sonnet으로 분석하면:
- 추출: 10,000 x 14 = 140,000 크레딧
- 선별: 9,999 x 1 = 9,999 크레딧
- **합계: ~150,000 크레딧**

월 5,000 크레딧으로는 **3.3% 진행 후 잔액 소진** → 분석 중단, 부분 결과 반환.

**비용 영향**:
- 5,000 크레딧 x 3.25원(Claude Sonnet 원가) = 16,250원 LLM 원가
- 14,900원 수입 대비 **적자**이긴 하지만 무한 손실은 아님 (잔액 소진 시 차단)

**보호 장치**: 현재 잔액 소진 차단이 있으므로 치명적 문제는 아님. 다만 사용자 경험이 매우 나쁨 (50MB 업로드 후 3%만 분석).

**권장**: 분석 시작 전 예상 크레딧 > 잔액이면 경고 UI 표시 (현재 `UsageEstimate`에서 일부 대응).

### 6-2. 1크레딧 최소값의 이중 효과

저가 모델에서 모든 청크가 1크레딧으로 반올림:
- Gemini Flash Lite: 원가 0.98원인데 10원 청구 → **10.2배 마크업**
- 짧은 청크(1,000자 이하)도 1크레딧 → 고정 비용화

**장점**: 소액 API 호출에서 높은 마진 확보, 수익 안정성.
**위험**: 사용자가 "왜 10배나 비싸지?"라고 느끼면 신뢰 저하. 특히 경쟁 서비스와 비교 시.

### 6-3. 토큰 추정 부정확성

OpenRouter가 usage 필드를 누락하면 `CHARS_PER_TOKEN=1.5`로 추정:
- 한국어 텍스트는 실제 ~1.0 char/token
- 추정은 실제 토큰의 ~67%만 계산
- MARGIN=3.0이 보상한다지만, 극단적으로 긴 시스템 프롬프트(누적 엔티티 컨텍스트)가 있으면 추정과 실제 사이 괴리 증가

**실제 위험**: 낮음. OpenRouter 대부분 usage를 반환하고, 추정이 과소하면 서비스 측 손실이지만 MARGIN이 커버.

### 6-4. 채팅 컨텍스트 윈도우 크리프

채팅 1메시지 = LLM 3회 호출. 대화가 길어지면:
- MAX_HISTORY_CHARS = 45,000 (~30K 토큰)
- 30K 토큰의 Claude Sonnet 입력 비용: (30000/1M)x3.00 = $0.09 → 약 38크레딧 (입력만)
- 출력 포함하면 메시지당 **40~60 크레딧** 가능

10회 대화 시 **400~600 크레딧** — Free 사용자 전체 크레딧의 4~6배.

**보호 장치**: `estimateChatCost()` 사전 체크 + 잔액 차단으로 무한 소비는 방지됨.

### 6-5. 동시 세션 / 경쟁 조건

동일 사용자가 탭 2개로 동시에 분석을 시작하면:
- 두 탭 모두 `checkSufficientBalance()` 통과 (잔액 > 0)
- 양쪽에서 동시에 크레딧 차감 시도
- **DB 레벨 `select_for_update()`**가 직렬화 → 데이터 정합성 보장
- 한쪽이 잔액 부족 402 → 부분 결과 반환

**평가**: 기술적으로 안전하지만, UX 측면에서 "두 분석 다 중간에 끊기는" 나쁜 경험 가능.

## 7. 사용자 매력도 평가

### 7-1. 가격 경쟁력 (한국 시장 기준)

| 비교 서비스 | 월 가격 | 제공 범위 |

| **StoryGraph Basic** | **4,900원** | 1,000크레딧, 전 모델 |
| **StoryGraph Pro** | **14,900원** | 5,000크레딧 + BYOK |
| ChatGPT Plus | ~28,000원 | GPT-4o (사용량 제한) |
| Claude Pro | ~28,000원 | Sonnet/Opus (사용량 제한) |
| Notion AI | ~14,000원/user | 내장 AI 기능 |
| Canva AI | ~21,000원 | 500크레딧 + 이미지 생성 |

**평가**: 4,900원~14,900원 구간은 한국 SaaS 시장에서 **매우 합리적인 가격대**. 특히 텍스트 분석이라는 특화 기능 대비 가성비가 좋음.

### 7-2. 가격 심리학 관점

**강점:**
- 3단 구조(Free/Basic/Pro) → 클래식 **디코이 효과** 활용
- Basic(4,900원)이 Pro(14,900원) 대비 "안 비싸 보이는" **앵커링** 효과
- 월간 만료 → **손실 회피** 심리로 사용 촉진

**약점:**
- 디코이 효과가 약함: Basic과 Pro 사이 3배 가격 차이지만 크레딧은 5배 → Pro가 너무 명백히 좋은 선택이라 **Basic의 존재 의미 약화**
- 크레딧이 무엇인지 직관적으로 파악 어려움 ("1크레딧 = 소설 1쪽 분석" 같은 매핑 부재)
- 연간 결제 할인 없음 → 장기 커밋먼트 유도 불가

### 7-3. 사용자 세그먼트별 매력도

| 세그먼트 | 매력도 | 이유 |
|---------|--------|------|
| 호기심 체험자 | 낮음 | Free 100크레딧으로 장편 1편도 힘듦 |
| 가벼운 독자/작가 | 높음 | Basic으로 월 5~8편 분석 가능 |
| 열혈 독자/작가 | 높음 | Pro로 충분한 분석량 |
| 출판/교육 기관 | 미흡 | 팀/기관 플랜 없음 |
| 개발자/연구자 | 높음 | BYOK로 자체 API 키 사용 가능 |

## 8. 비즈니스/마케팅 구조 평가

### 8-1. 과금 유도 구조 (Monetization Funnel)

```
무료 체험 → 크레딧 소진 → 유료 전환 → 추가 구매 → 장기 유지
```

**현재 퍼널 문제점:**

1. **진입**: Free 100크레딧으로 서비스 가치를 충분히 보여주기 어려움 → 전환율 저하 예상 (업계 평균 freemium 전환율: 3~5%, 최상위: 8~15%)
2. **전환 유도**: 크레딧 소진 시 "잔액 부족" 경고만 있고, **업그레이드 CTA가 약함**.
3. **추가 구매**: 크레딧 패키지가 "준비 중" → Basic/Pro 사용자가 크레딧 소진 시 다음 달까지 대기.
4. **장기 유지**: 연간 결제 할인, 로열티 프로그램, 이월 혜택 등 장기 유지 장치 전무.

### 8-2. 누락된 비즈니스 장치

| 장치 | 상태 | 기대 효과 |
|------|------|----------|
| 연간 결제 (20% 할인) | 부재 | LTV 증가, 이탈률 감소 |
| 크레딧 패키지 | 미출시 | 즉시 매출 15~30% 증가 |
| 리퍼럴 프로그램 | 부재 | CAC 절감, 바이럴 성장 |
| 유료 체험기간 | 부재 | 전환율 2~3배 향상 |
| 사용량 알림 (50%/80%/100%) | 부분 | 업그레이드 전환 트리거 |
| 팀/기관 플랜 | 부재 | B2B 시장 진입 |
| BYOK 모델 할인 | 부재 | Pro 사용자 BYOK 유도 → 원가 제거 |

### 8-3. 가격 체계의 비즈니스 성숙도

업계 SaaS 가격 성숙도 모델 기준:

- **Level 1** (Cost-Plus): 원가에 마진을 올려 가격 책정 → **현재 여기**
- **Level 2** (Competitor-Based): 경쟁사 가격 참조
- **Level 3** (Value-Based): 고객이 인지하는 가치 기반
- **Level 4** (Dynamic): 세그먼트별 차별화 가격

현재 Level 1 단계. MARGIN=3.0이라는 고정 마크업에 의존. 모델별/기능별 가치 차이를 가격에 반영하지 않음.

## 9. 권장사항

### 즉시 조치 (높은 우선순위)

1. **크레딧 패키지 출시**: 이미 DB 구조가 준비됨. UI만 활성화하면 즉시 매출 증가 가능.
2. **Pro 플랜 마진 보호**: Pro 월 크레딧 4,000으로 하향 또는 가격 17,900원으로 인상, 또는 프리미엄 모델 크레딧 가중치.
3. **Free 플랜 초기 경험 개선**: 첫 가입 시 200~300 크레딧 일회성 보너스 → 장편 1편 완전 분석 가능.

### 중기 조치 (1~3개월)

4. **연간 결제 도입**: Basic 연간 49,000원(17% 할인), Pro 연간 149,000원(17% 할인).
5. **환율 리뷰 체계**: 분기별 USD_TO_KRW 검토. 현재 1,400원은 과소 → 1,450원으로 조정 권장.
6. **크레딧-가치 매핑 명확화**: "1크레딧 ≈ 소설 1페이지(2,000자) 분석" 같은 직관적 설명 추가.
7. **사용량 알림**: 50%, 80%, 100% 잔액 도달 시 알림 + 업그레이드/패키지 구매 CTA.

### 장기 조치 (3~6개월)

8. **팀/기관 플랜**: 교육기관/출판사 대상 B2B 티어.
9. **BYOK 인센티브**: Pro 사용자가 BYOK 사용 시 크레딧 소진 없음 → 서비스 원가 = 0.
10. **부분 이월**: Pro 사용자에게 미사용 크레딧 최대 20% 이월 허용.

## 10. 요약 판정

| 평가 항목 | 등급 | 코멘트 |
|----------|------|--------|
| (1) 심각한 문제 | **주의** | Pro 마진 역전 가능성, 환율 하드코딩 |
| (2) 극단적 케이스 | **양호** | 잔액 소진 차단으로 무한 손실 방지됨. DoW 공격 내성 있음 |
| (3) 사용자 매력도 | **양호** | 가격 자체는 경쟁력 있으나 Free 체험이 빈약 |
| (4) 비즈니스 구조 | **미흡** | 퍼널 후반부(추가 구매, 장기 유지) 장치 부재 |

**전체 평가**: 기술적 과금 인프라는 견고하게 구축되어 있고 (idempotency, select_for_update, append-only ledger 등), 가격 수준도 한국 시장에 적합. 하지만 비즈니스 성장 장치가 부족. 크레딧 패키지 출시와 Free 플랜 초기 보너스만 해도 전환율과 매출에 유의미한 개선 기대.
