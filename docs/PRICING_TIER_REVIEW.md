## 2. 구독 유인 충분성 평가

### 2-1. Free → Basic 전환 유인: **불충분**

확정안에서 가장 심각한 구조적 문제입니다.

**핵심 수치:**
- Free 월 500cr + Gemini Flash(59cr/장편) = **월 ~8편 분석 가능**
- 첫 달 1,500cr = **~25편 분석 가능**

일반적인 소설 독자의 월간 독서량은 2~4편입니다. Free 티어의 500cr/월이 저가 모델 기준으로 이미 일반 독자의 수요를 **2~4배 초과**합니다.

**결과:** Gemini Flash 품질에 만족하는 사용자(대다수)는 Basic으로 전환할 이유가 없습니다. Basic의 주요 차별점인 "전체 모델 접근"은 GPT-4o/Claude Sonnet을 써보고 싶은 사용자에게만 유효하고, 대부분의 사용자는 기본 모델로 충분한 결과를 얻습니다.

**업계 벤치마크 비교:**
| 서비스 | Free 티어 설계 | 전환 유도 방식 |
|--------|--------------|--------------|
| ChatGPT | 제한적 사용량 + 느린 응답 | 속도/모델 차등 |
| Notion AI | 10회 무료 | 극도로 제한적 |
| Canva | 제한적 템플릿 + 워터마크 | 기능 차등 |
| **StoryGraph** | **월 8편 분석 (충분)** | **모델 차등만** |

대부분의 성공적 freemium 서비스는 Free 티어에서 "서비스 가치를 체험하되 불편함을 느끼는" 지점을 설계합니다. 현재 StoryGraph Free는 **불편함이 거의 없습니다**.

### 2-2. Basic → Pro 전환 유인: **약함**

**핵심 수치:**
- Basic 5,000cr + Gemini Flash = **월 ~84편** (비현실적으로 과잉)
- Basic 5,000cr + Claude Sonnet = **월 ~3.6편** (대부분 충분)
- Pro 전환 교차점: 월 ~14,000cr 소비 시 (매우 헤비 사용자만 해당)

Basic에서 Pro로 전환할 유인은 사실상 3가지뿐입니다:
1. **BYOK 필요** — 개발자/연구자 세그먼트 (전체 사용자의 5% 미만 추정)
2. **파일 크기 >10MB** — 대하소설 분석자 (매우 드문 케이스)
3. **Sonnet 헤비 사용** — 월 3.6편 이상을 Sonnet으로 분석하는 경우

**Price-to-value 인식 문제:**
- Basic 4,900원 = 하루 ~163원 = 커피 1/30잔
- Pro 16,900원 = 하루 ~563원 = 커피 1/9잔
- 가격 차이 12,000원에 대해 사용자가 인지하는 추가 가치가 "BYOK"과 "파일 크기"뿐이라면, 대부분은 Basic에 머무릅니다.

### 2-3. Free 가입보너스의 역효과

1,000cr 가입보너스는 "서비스 가치 체험" 목적이지만, 부작용이 있습니다:

- 첫 달 1,500cr로 Flash 장편 25편 분석 → 사용자가 "이 서비스 값어치를 이미 다 봤다"고 인식
- 2개월차에 500cr로 줄어들지만 여전히 8편 가능
- **보너스가 전환을 촉진하는 대신, 무료 체류를 연장하는 효과**

비교: 넷플릭스 무료체험은 "7일"이라는 시간 제한으로 급박감을 만들었고, 스포티파이 Free는 "광고+셔플 전용"이라는 기능 제한으로 전환을 유도합니다. StoryGraph의 보너스 설계는 이러한 급박감/불편함이 없습니다.

## 3. 고가 기본 요금제 추가 검토

### 3-1. 현재 가격 체계의 구조적 공백

```
  0원              4,900원                        16,900원
   │                 │                               │
 Free ──────────── Basic ─────────────────────────── Pro
                     ↑                               ↑
              "대부분 여기서 충분"           "BYOK 필요한 소수만"
```

**문제:** Basic과 Pro 사이에 12,000원 간격이 있고, 가격 점프(3.45배)에 비해 인지 가치 차이가 크지 않습니다. 크레딧은 4배(5,000→20,000)이지만, 이미 Basic에서 대부분의 사용 시나리오가 커버됩니다.

### 3-2. 중간 티어 추가 방안: **권장하지 않음**

**Standard (9,900원, 12,000cr) 같은 중간 티어를 추가하면:**

- 3단 구조의 디코이 효과가 4단으로 분산 → 선택 피로(choice paralysis) 증가
- Basic이 이미 과잉 상태에서 중간 티어도 과잉이 됨
- 차별화 포인트 부족 (BYOK는 Pro 전용, 모델은 Basic부터 전부 제공)
- 크레딧 양으로만 차별화하면 "크레딧을 다 쓸 수 있는 사용자가 몇이나 되는가?"라는 근본 문제에 봉착

**결론:** 현재 구조에서 중간 가격대를 추가하는 것은 문제를 해결하지 못합니다.

### 3-3. 실제로 필요한 것: 기존 티어의 가치 구조 재설계

문제의 핵심은 "더 비싼 요금제가 없어서"가 아니라, **현재 Free와 Basic이 너무 관대해서** 상위 티어로 올라갈 동기가 없다는 점입니다.

## 4. 구체적 개선 권장사항

### 4-1. [핵심] Free 티어 크레딧 하향: 500 → 200cr/월

| 항목 | 현재 (500cr) | 권장 (200cr) |
|------|-------------|-------------|
| Flash 장편 | ~8편 | **~3편** |
| Flash 단편 | ~70편 | ~28편 |
| Sonnet 사용 | 불가(2모델 제한) | 불가 |

**200cr의 설계 의도:**
- 장편 3편 = "서비스 가치를 충분히 체험"
- 장편 4편부터 = "크레딧이 부족하다" → Basic 전환 유인 발생
- 월 4편 이상 분석하는 적극적 독자가 전환 타겟 세그먼트

**가입보너스 조정:** 1,000cr → 500cr
- 첫 달 700cr = Flash 장편 ~12편 → 충분한 체험
- 2개월차부터 200cr = 부족함 시작 → 전환 압력

### 4-2. [핵심] 기능 기반 차별화 강화

크레딧 양이 아닌 **기능**으로 차등을 두어야 합니다:

| 기능 | Free | Basic | Pro |
|------|------|-------|-----|
| 분석 | O | O | O |
| 채팅 질의 | **3회/분석** | **무제한** | 무제한 |
| 관계도 내보내기 (이미지) | X | O | O |
| 버전 히스토리 | **최근 3개** | **최근 10개** | 무제한 |
| 동시 저장 그래프 | **3개** | **20개** | 무제한 |
| 모델 선택 | 2종 | 전체 | 전체 |
| BYOK | X | X | O |

**채팅 3회 제한**이 가장 강력한 전환 유도장치입니다. 분석 결과에 대해 AI에 질문하는 기능은 핵심 가치인데, 3회면 "맛보기"만 가능합니다.

**저장 그래프 3개 제한** 역시 효과적입니다. 3번째 분석까지는 무료, 4번째부터 "저장 공간이 부족합니다 — Basic으로 업그레이드" 메시지 노출.

### 4-3. [권장] Basic 가격 유지, Pro에 실질적 프리미엄 추가

Basic 4,900원은 한국 SaaS 시장에서 진입 장벽이 낮은 적절한 가격입니다. 이 가격을 올리기보다, Pro의 가치를 높이는 것이 전략적으로 유리합니다.

**Pro 추가 기능 후보:**
| 기능 | 설명 | 구현 난이도 |
|------|------|-----------|
| **일괄 분석** | 여러 파일을 한 번에 분석 큐에 등록 | 중간 |
| **분석 보고서 PDF 내보내기** | 인물 관계도 + 통계 + 요약을 PDF로 | 중간 |
| **시리즈 연결** | 여러 권의 분석 결과를 시리즈로 연결 | 높음 |
| **API 접근** | 외부에서 분석 API 직접 호출 | 중간 |
| **우선 처리** | 분석 큐에서 Pro 사용자 우선 실행 | 낮음 |

이 중 **일괄 분석**과 **PDF 내보내기**는 구현 대비 인지 가치가 높습니다.

### 4-4. [대안] 고가 기본 요금제 대신 "연간 플랜" 우선 도입

PRICING_FINAL.md 로드맵에 "1~3개월: 연간 결제"가 있는데, 이것이 더 고가 티어 추가보다 우선입니다.

| 플랜 | 월간 | 연간 (17% 할인) | 연간 월 환산 |
|------|------|---------------|------------|
| Basic | 4,900원 | 49,000원 | 4,083원 |
| Pro | 16,900원 | 169,000원 | 14,083원 |

연간 결제는:
- **즉각적인 현금흐름 개선** (12개월치 선수금)
- **이탈률 대폭 감소** (연간 결제 사용자의 갱신율이 월간 대비 2~3배)
- **사용자 커밋먼트 증가** ("이미 결제했으니 써야지" 심리)
- 구현 비용이 새 티어 추가보다 낮음

## 5. "더 비싼 기본 요금제" 최종 판단

### 단도직입적 결론: **지금은 추가하지 않는 것이 맞습니다.**

**이유:**

1. **근본 원인이 다름**: 전환율이 낮을 것으로 예상되는 이유는 "비싼 선택지가 없어서"가 아니라 "Free/Basic이 너무 관대해서"입니다. 고가 티어를 추가해도 Free 사용자가 그쪽으로 올라갈 유인이 추가로 생기지 않습니다.

2. **런칭 전 단계**: 사용자 데이터 없이 4개 이상의 티어를 설계하면 복잡성만 증가합니다. 3단 구조로 런칭하고, 실제 사용 패턴 데이터를 확보한 후 (3~6개월) 티어 확장을 검토하는 것이 리스크가 낮습니다.

3. **가격 인상은 쉽지만 인하는 어려움**: SaaS에서 기존 사용자의 가격을 올리는 것은 극도로 민감합니다. 처음부터 보수적으로 시작하고, 가치를 입증한 후 프리미엄 티어를 추가하는 것이 안전합니다.

4. **대신 해야 할 것**: Free 크레딧 하향 + 기능 차별화 강화가 동일한 비즈니스 목표(전환율 향상)를 더 낮은 구현 비용으로 달성합니다.

### 추가 가능 시점

아래 조건 중 2개 이상 충족 시 "Standard" 또는 "Enterprise" 티어 추가를 검토할 수 있습니다:

- [ ] Basic 사용자 중 30% 이상이 월 3,000cr 이상 소비
- [ ] Pro 사용자 중 50% 이상이 BYOK를 사용하지 않음 (= BYOK 외의 이유로 Pro 선택)
- [ ] B2B 문의가 월 5건 이상 발생
- [ ] Basic→Pro 전환율이 5% 미만

## 6. 조치 우선순위 종합

| 우선순위 | 조치 | 기대 효과 | 난이도 |
|---------|------|----------|--------|
| **1** | Free 크레딧 500→200, 보너스 1000→500 | 전환 압력 2.5배 증가 | 낮음 (상수 변경) |

| **4** | 크레딧 패키지 출시 | 즉시 매출 15~30% 예상 | 낮음 (UI만 활성화) |

| **6** | Pro 프리미엄 기능 추가 (PDF, 일괄) | Pro 전환 유인 강화 | 높음 |
