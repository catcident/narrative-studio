## 6. 핵심 성과

### 주인공 "나" 파이프라인
- LLM A에서 "나"를 엔티티로 추출 → `reviewEntityMerges()`에서 실제 이름과 병합 → `entityNameMapping`으로 LLM B 엔트리 이름 변환
- 실제소설 테스트에서 주인공 "나"가 42개 엔트리로 전체 최다 달성
- L08, L15 등 1인칭 테스트에서도 안정적 동작

### 카테고리 균형
- LLM B 프롬프트의 카테고리 우선순위 규칙으로 personality 편중 방지
- 실제소설: appearance 14, ability 16, personality 27 — 한쪽으로 극단적 치우침 없음

### 무효 엔티티 필터
- `INVALID_ENTITY_NAMES` ("세계", "여기" 등) + `CATEGORY_AS_NAME` 필터로 무의미한 엔트리 제거
- 전 테스트에서 invalid entity 0건
