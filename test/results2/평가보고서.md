### 01. 기본추출 (8/10)

#### 테스트 목적
가장 기본적인 소설 텍스트에서 인물, 동물 캐릭터, 장소, 아이템을 정확히 추출하고, 별칭(까망이, 잿빛이)과 기본 관계(친구, 가족, 돌봄)를 식별하는지 검증한다.

#### 기대 결과
- **엔티티**: 민수(character), 수진(character), 검은 고양이/까망이(character), 회색 고양이/잿빛이(character), 골목(location)
- **관계**: 민수-수진(같은 반 친구), 민수-까망이(돌봄), 수진-까망이(돌봄), 까망이-잿빛이(부모-자식)
- **별칭**: 검은 고양이 = 까망이, 회색 고양이 = 잿빛이

#### 실제 결과
- **엔티티 (10개)**: 검은 고양이(aliases: 까망이), 민수, 참치캔, 수진, 골목, 비, 쓰레기통, 회색 고양이(aliases: 잿빛이), 담요, 우유
- **관계 (6개)**: 검은 고양이-민수(관련), 민수-수진(친구), 수진-검은 고양이(관련), 회색 고양이-검은 고양이(가족), 민수-회색 고양이(관련), 수진-회색 고양이(관련)

#### 평가

**잘된 점**:
- 주요 캐릭터(민수, 수진, 까망이, 잿빛이) 모두 정확히 추출
- 별칭 처리 정확 (까망이, 잿빛이를 aliases로 등록)
- 까망이-잿빛이 가족 관계 정확
- 민수-수진 친구 관계 정확

**부족한 점**:
- 불필요한 엔티티 과다 추출: 참치캔, 비, 쓰레기통, 담요, 우유는 스토리에서 중요하지 않은 소품
- "관련"이라는 모호한 관계 타입이 과다 사용됨. 민수-까망이는 "돌봄" 관계가 더 적절

### 02. 시점변경_1인칭 (8/10)

#### 테스트 목적
1인칭 시점이 화(chapter)마다 바뀌는 소설에서, "나"가 각각 다른 인물(서준, 수아)임을 인식하고, 3화에서 3인칭으로 전환될 때 동일 인물을 정확히 매칭하는지 검증한다.

#### 기대 결과
- **엔티티**: 한서준(character), 이수아(character), 김 사장(character), 박재민(character), 진아(character), 블루문 카페(location)
- **시점 인식**: 1화 "나" = 한서준, 2화 "나" = 이수아, 3화 = 3인칭
- **관계**: 서준-박재민(동료), 수아-진아(룸메이트/친구), 서준-김사장(단골-주인), 서준-수아(만남)

#### 실제 결과
- **엔티티 (11개)**: 한서준(aliases: 서준 씨, 서준아), 블루문 카페, 김 사장, 아메리카노, 박재민, 이수아, 캔버스, 진아, 푸른 달이 뜬 카페 풍경, 캔버스 가방, 물감이 묻은 앞치마
- **관계 (4개)**: 한서준-김사장(관련), 한서준-박재민(동료), 이수아-진아(친구), 한서준-이수아(관련)

#### 평가

**잘된 점**:
- 1인칭 시점 전환을 정확하게 처리. "나"를 1화에서는 한서준, 2화에서는 이수아로 올바르게 식별
- 3화에서 3인칭 전환 시 기존 엔티티와 정확히 매칭
- 한서준의 aliases(서준 씨, 서준아) 정확

**부족한 점**:
- 불필요한 아이템 엔티티: 아메리카노, 캔버스, 캔버스 가방, 물감이 묻은 앞치마
- "푸른 달이 뜬 카페 풍경"을 concept으로 추출한 것은 과잉
- 한서준-김사장 관계가 "관련"으로만 표현됨

#### 기대 결과

- **별칭**: 태현 = 전하, 서연 = 마녀
- **핵심**: 4가지 검을 각각 별개 엔티티로 정확히 구분

#### 실제 결과
- **엔티티 (18개)**: 철민, 태현(aliases: 전하), 윤호, 의식용 검, 전투용 검, 서연(aliases: 마녀), 도현, 연습용 검, 낡은 검 등

#### 평가

**잘된 점**:
- 4가지 검을 모두 별개 엔티티로 정확히 구분 -- 핵심 테스트 통과

- 양방향 중복 관계 생성 (태현-윤호, 도현-서연)
- 도현-서연 관계가 "동료"로 표현됨. 실제로는 "공생/교환" 관계

### 06. 별칭_이름변경 (8/10)

#### 테스트 목적
캐릭터가 이야기 진행에 따라 여러 이름을 갖게 되는 경우(검은 여우 -> 까미 -> 야무라, 토끼 -> 달토끼 -> 하양이)의 별칭 처리 검증.

#### 기대 결과
- **별칭 처리**: 검은 여우 = 까미 = 야무라, 토끼 = 달토끼 = 하양이
- **핵심 관계**: 까미-하양이(친구), 까미-할머니(양육), 은빛 여우 전설-야무라(연관)

#### 실제 결과
- **엔티티 (10개)**: 검은 여우(aliases: 까미, 야무라), 토끼(aliases: 달토끼, 하양이), 부엉이 어른, 큰수달, 작은수달, 할머니, 은빛 여우(concept)
- **관계 (6개)**: 검은 여우-토끼(친구), 큰수달-검은 여우(친구), 큰수달-토끼(친구), 작은수달-검은 여우(친구), 작은수달-토끼(친구), 검은 여우-할머니(가족)

#### 평가

**잘된 점**:
- **핵심 별칭 처리 완벽**: 검은 여우→까미→야무라, 토끼→달토끼→하양이 모두 하나의 엔티티에 통합
- 은빛 여우를 별도 concept으로 분리한 것은 적절

**부족한 점**:
- 은빛 여우(concept)와 야무라(character) 간의 관계 누락 (핵심 서사 연결)
- 큰수달-작은수달의 "형제" 관계 누락 ("수달 형제"로 명시)

### 08. 대명사_지시어 (6/10)

#### 테스트 목적
"그", "그녀", "그 여자", "그 사람", "나" 등 대명사와 지시어가 빈번하게 사용되는 텍스트에서, 이들을 올바른 인물로 해소(resolve)하는지 검증.

#### 기대 결과
- **캐릭터**: 재원, 하윤, 서연, 민혁
- **관계**: 재원-하윤(호감/연인 발전), 하윤-서연(자매), 재원-민혁(고등학교 동창)
- **핵심**: "그"→재원, "그녀"→하윤/서연(문맥에 따라), "나"→재원이 올바르게 해소되었는지

#### 실제 결과
- **엔티티 (5개)**: 재원, 하윤, 카페, 서연, 민혁
- **관계 (3개)**: 재원-하윤(관련/"호감"), 하윤-서연(가족/"자매"), 재원-민혁(친구/"고등학교 동창")

#### 평가

**잘된 점**:
- 4명 캐릭터 모두 정확 추출. 대명사를 별도 엔티티로 생성하지 않음
- "나"(2화)를 재원으로 올바르게 식별
- 하윤-서연 자매, 재원-민혁 친구 관계 정확

**부족한 점**:
