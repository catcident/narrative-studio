# 테스트 데이터

지식그래프 추출 파이프라인 테스트용 소설 텍스트 모음.

## 파일 목록

| 파일 | 테스트 목적 | 핵심 검증 포인트 |
|------|-----------|----------------|
| `01_기본추출.txt` | 기본 엔티티/관계 추출 | 2개 chapter 인식, 캐릭터 4개(민수,수진,까망이,잿빛이), 장소(골목), 아이템(참치캔,쓰레기통) |
| `02_시점변경_1인칭.txt` | 1인칭 시점 변경 | "나"가 서준과 수아 두 명이므로 자동 병합되면 안됨. 블루문카페/김사장은 동일 엔티티로 통합되어야 함 |
| `03_동명이인_유사엔티티.txt` | 유사 이름 구별 | "의식용 검"과 "전투용 검"은 별개 엔티티. "서연의 집"과 "도현의 오두막"도 별개. 같은 종류지만 다른 것 구분 |
| `04_복잡한관계망.txt` | 가족 관계 + 시간 표현 | 3세대 가족관계(할머니→아버지→은서), 시간마커("10년 전","일주일 후","다음 날"), 쌍둥이(강순옥/강순희) |
| `05_세계관_컨셉.txt` | concept 엔티티 + 조직 | 균열/특수국/감지사/강화사/해석사/봉인사 등 concept 추출. 팀 소속관계. 마물 등급 체계 |
| `06_별칭_이름변경.txt` | 엔티티 별칭/이름 변경 | "검은 여우"→"까미"→"야무라" 동일 엔티티. "달토끼"→"하양이" 동일 엔티티. LLM 병합 검토에서 잡아야 함 |
| `07_대규모_엔티티.txt` | 다수 엔티티 처리 | 20명+ 캐릭터, 3개 그룹(A/B/C반), 학부모-자녀 관계, 소속 관계 |
| `08_대명사_지시어.txt` | 대명사/지시어 해석 | "그/그녀"→실제 인물로 resolve, 2화 1인칭 "나"→재원, "그 여자"→하윤, 서연의 "그녀" 혼동 방지 |
| `09_무협_세대_소속.txt` | 세대별 소속 + 비공식 그룹 | 화산파(조직)→2대/3대 제자, 사제 관계(유이설→청명, 백청능→윤종), "청명이들"(비공식 그룹), 남궁세가 가계, 흑풍채 적대 |

## 사용 방법

웹 앱에서 텍스트 파일을 업로드하여 지식그래프를 생성하고 결과를 확인합니다.

### 검증 체크리스트

- [ ] chapter/scene이 올바르게 인식되는가
- [ ] 엔티티가 누락 없이 추출되는가
- [ ] 같은 엔티티가 다른 이름으로 분리되지 않았는가 (LLM 병합 검토)
- [ ] 다른 엔티티가 잘못 합쳐지지 않았는가 (특히 대명사 "나"/"그"/"그녀")
- [ ] 대명사/지시어가 실제 인물로 올바르게 해석되었는가
- [ ] 세대/계층 소속 관계가 올바른가 (사제, 상하 조직)
- [ ] 유사 아이템이 올바르게 구분되는가 (의식용 검 vs 전투용 검)
- [ ] 관계 타입이 올바른가 (가족/친구/소속 등)
- [ ] 시간 표현이 time_marker에 올바르게 기록되는가
- [ ] concept 카테고리 엔티티가 추출되는가
